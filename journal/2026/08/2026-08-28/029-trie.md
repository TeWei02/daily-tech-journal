## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「Trie 的空间与查询权衡」做一次整理，重点放在能直接落地的部分。

## 要点

- 用字典嵌套实现简单但内存开销大，数组实现更紧凑
- 前缀查询与自动补全共用同一结构
- 优化前后都要有可复现的基准数据。

## 示例

```python
def insert(root, word):
    node = root
    for ch in word:
        node = node.setdefault(ch, {})
    node['#'] = True
```

## 易错点

- 计数场景要在节点上保存额外字段
