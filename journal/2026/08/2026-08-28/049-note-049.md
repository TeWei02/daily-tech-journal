# 拥塞控制算法的影响：性能与复杂度权衡

**日期**：2026-08-28　**领域**：网络　**编号**：49/115

## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「拥塞控制算法的影响」做一次整理，重点放在能直接落地的部分。

## 要点

- BBR 基于带宽与延迟建模，在高丢包链路上通常优于 CUBIC
- 切换算法可在线生效，但对已有连接不回溯
- 优化前后都要有可复现的基准数据。

## 示例

```bash
sysctl net.ipv4.tcp_congestion_control
sysctl -w net.ipv4.tcp_congestion_control=bbr
```

## 易错点

- 盲目开启 BBR 在浅缓冲链路上收益有限

## 小结

拥塞控制算法的影响 在性能与复杂度权衡这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
