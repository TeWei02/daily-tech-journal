## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「RAII 与资源释放顺序」做一次整理，重点放在能直接落地的部分。

## 要点

- 析构按构造逆序执行，成员按声明顺序构造、逆序析构
- 异常路径同样会析构，这正是 RAII 的价值
- 优化前后都要有可复现的基准数据。

## 示例

```cpp
struct File {
    FILE* f;
    File(const char* p) : f(fopen(p, "r")) {}
    ~File() { if (f) fclose(f); }
};
```

- 成员初始化列表顺序应与声明一致，否则警告
