# 幂等重试与退避：性能与复杂度权衡

**日期**：2026-08-28　**领域**：系统　**编号**：85/115

## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「幂等重试与退避」做一次整理，重点放在能直接落地的部分。

## 要点

- 重试要区分可重试错误与业务失败
- 加入抖动避免同步重试造成脉冲
- 优化前后都要有可复现的基准数据。

## 示例

```python
delay = min(cap, base * 2 ** attempt) * random.uniform(0.8, 1.2)
```

## 易错点

- 对写接口无限重试会放大故障

## 小结

幂等重试与退避 在性能与复杂度权衡这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
