# 特征穿越与数据泄漏：性能与复杂度权衡

**日期**：2026-08-28　**领域**：数据　**编号**：95/115

## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「特征穿越与数据泄漏」做一次整理，重点放在能直接落地的部分。

## 要点

- 训练特征只能使用预测时刻之前可获得的信息
- 时间序列切分不要随机打乱
- 优化前后都要有可复现的基准数据。

## 示例

```python
train = df[df.ts < cutoff]
valid = df[df.ts >= cutoff]
```

## 易错点

- 用全局统计量做标准化会造成泄漏

## 小结

特征穿越与数据泄漏 在性能与复杂度权衡这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
