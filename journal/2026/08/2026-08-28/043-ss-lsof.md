# ss 与 lsof 定位端口占用：性能与复杂度权衡

**日期**：2026-08-28　**领域**：Linux　**编号**：43/115

## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「ss 与 lsof 定位端口占用」做一次整理，重点放在能直接落地的部分。

## 要点

- ss -ltnp 比 netstat 更快且信息完整
- lsof -p 看到进程持有的全部 fd 与文件
- 优化前后都要有可复现的基准数据。

## 示例

```bash
ss -ltnp 'sport = :8080'
lsof -i :8080 -sTCP:LISTEN
```

## 易错点

- 容器内 ss 可能看不到宿主机命名空间的连接

## 小结

ss 与 lsof 定位端口占用 在性能与复杂度权衡这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
