# 特征穿越与数据泄漏：常见陷阱与错误示范

**日期**：2026-08-28　**领域**：数据　**编号**：6/115

## 背景

多数线上问题不是不会用，而是用错了一个细节。这里围绕「特征穿越与数据泄漏」做一次整理，重点放在能直接落地的部分。

## 要点

- 训练特征只能使用预测时刻之前可获得的信息
- 时间序列切分不要随机打乱
- 把踩过的坑写成检查项，比背结论更有效。

## 示例

```python
train = df[df.ts < cutoff]
valid = df[df.ts >= cutoff]
```

## 易错点

- 用全局统计量做标准化会造成泄漏

## 小结

特征穿越与数据泄漏 在常见陷阱与错误示范这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
