## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「拓扑排序与入度表」做一次整理，重点放在能直接落地的部分。

## 要点

- Kahn 算法逐层剥入度为零的点，天然给出分层信息
- 若结果长度小于节点数说明有环
- 优化前后都要有可复现的基准数据。

## 示例

```python
indeg = [0] * n
for u, v in edges:
    indeg[v] += 1
q = deque(i for i in range(n) if indeg[i] == 0)
```

## 易错点

- 有环时不要无限循环，需提前判断
