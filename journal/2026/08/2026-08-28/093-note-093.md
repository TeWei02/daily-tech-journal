# 去重与近似的取舍：性能与复杂度权衡

**日期**：2026-08-28　**领域**：数据　**编号**：93/115

## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「去重与近似的取舍」做一次整理，重点放在能直接落地的部分。

## 要点

- 精确去重占内存，HyperLogLog 误差可控但不可枚举
- 集合交并场景要注意误差叠加
- 优化前后都要有可复现的基准数据。

## 示例

```python
from datasketch import HyperLogLog
hll = HyperLogLog(p=14)
```

## 易错点

- 对账场景不能使用近似算法

## 小结

去重与近似的取舍 在性能与复杂度权衡这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
