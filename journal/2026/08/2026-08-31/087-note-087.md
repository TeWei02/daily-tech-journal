# 读写锁与场景选择：版本迁移与兼容处理

**日期**：2026-08-31　**领域**：并发　**编号**：87/115

## 背景

升级前先确认依赖链上的行为差异。这里围绕「读写锁与场景选择」做一次整理，重点放在能直接落地的部分。

## 要点

- 读多写少用读写锁，写竞争激烈时可能不如互斥量
- 写饥饿需要公平模式或写优先策略
- 灰度期间保留回退路径。

## 示例

```cpp
std::shared_mutex mu;
{ std::shared_lock lk(mu); read(); }
{ std::unique_lock lk(mu); write(); }
```

## 易错点

- 读锁里做长耗时任务会阻塞写者

## 小结

读写锁与场景选择 在版本迁移与兼容处理这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
