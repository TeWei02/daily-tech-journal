# TLS 握手耗时拆解：版本迁移与兼容处理

**日期**：2026-08-31　**领域**：网络　**编号**：63/115

## 背景

升级前先确认依赖链上的行为差异。这里围绕「TLS 握手耗时拆解」做一次整理，重点放在能直接落地的部分。

## 要点

- 1-RTT 与 0-RTT 差异在会话复用，0-RTT 有重放风险
- 证书链不完整会导致部分客户端握手失败
- 灰度期间保留回退路径。

## 示例

```bash
openssl s_client -connect host:443 -servername host -tls1_3
```

## 易错点

- SNI 缺失会拿到默认站点证书

## 小结

TLS 握手耗时拆解 在版本迁移与兼容处理这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
