# gRPC 流控与超时传递：版本迁移与兼容处理

**日期**：2026-08-31　**领域**：网络　**编号**：65/115

## 背景

升级前先确认依赖链上的行为差异。这里围绕「gRPC 流控与超时传递」做一次整理，重点放在能直接落地的部分。

## 要点

- DEADLINE_EXCEEDED 会在跨服务调用链上传播并逐级缩短
- 流控基于 HTTP/2 窗口，慢消费者会反压上游
- 灰度期间保留回退路径。

## 示例

```bash
ctx, cancel = context.with_timeout(ctx, 2.0)
resp = stub.Query(ctx, req)
```

## 易错点

- 忘记取消会泄漏协程与连接

## 小结

gRPC 流控与超时传递 在版本迁移与兼容处理这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
