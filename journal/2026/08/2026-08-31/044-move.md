# move 语义与返回值优化：版本迁移与兼容处理

**日期**：2026-08-31　**领域**：C/C++　**编号**：44/115

## 背景

升级前先确认依赖链上的行为差异。这里围绕「move 语义与返回值优化」做一次整理，重点放在能直接落地的部分。

## 要点

- 返回局部对象优先依赖 NRVO，显式 move 反而阻止优化
- 被 move 后的对象处于有效但未指定状态，不要假设为空
- 灰度期间保留回退路径。

## 示例

```cpp
std::vector<int> build() {
    std::vector<int> v;
    v.reserve(1024);
    return v;
}
```

## 易错点

- 对 const 对象 move 会退化成拷贝

## 小结

move 语义与返回值优化 在版本迁移与兼容处理这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
