# 慢查询定位流程：版本迁移与兼容处理

**日期**：2026-08-31　**领域**：数据库　**编号**：69/115

## 背景

升级前先确认依赖链上的行为差异。这里围绕「慢查询定位流程」做一次整理，重点放在能直接落地的部分。

## 要点

- 先看 slow log 与执行计划，再判断是索引问题还是回表过多
- 覆盖索引可消除回表，但会增加索引体积
- 灰度期间保留回退路径。

## 示例

```sql
EXPLAIN ANALYZE SELECT id, name FROM t WHERE code = 'x';
```

## 易错点

- 只看 EXPLAIN 不够，实际行数与估算差异大时要 analyze

## 小结

慢查询定位流程 在版本迁移与兼容处理这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
