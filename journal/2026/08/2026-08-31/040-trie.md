## 要点

- 用字典嵌套实现简单但内存开销大，数组实现更紧凑
- 前缀查询与自动补全共用同一结构
- 灰度期间保留回退路径。

## 示例

```python
def insert(root, word):
    node = root
    for ch in word:
        node = node.setdefault(ch, {})
    node['#'] = True
```

## 易错点

- 计数场景要在节点上保存额外字段
