# 堆在 Top-K 场景的应用：常见陷阱与错误示范

**日期**：2026-08-27　**领域**：算法　**编号**：52/115

## 背景

多数线上问题不是不会用，而是用错了一个细节。这里围绕「堆在 Top-K 场景的应用」做一次整理，重点放在能直接落地的部分。

## 要点

- 求最大 K 个用最小堆，堆大小维持 K，复杂度 O(n log K)
- Python heapq 是最小堆，取相反数实现最大堆
- 把踩过的坑写成检查项，比背结论更有效。

## 示例

```python
h = []
for x in nums:
    heappush(h, x)
    if len(h) > k:
        heappop(h)
```

## 易错点

- nlargest 在 K 很小时内部也会做优化，不必手写

## 小结

堆在 Top-K 场景的应用 在常见陷阱与错误示范这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
