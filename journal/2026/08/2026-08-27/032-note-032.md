# 特征穿越与数据泄漏：落到真实场景的改造

**日期**：2026-08-27　**领域**：数据　**编号**：32/115

## 背景

把它放进真实流程，通常要补上配置、日志与失败分支。这里围绕「特征穿越与数据泄漏」做一次整理，重点放在能直接落地的部分。

## 要点

- 训练特征只能使用预测时刻之前可获得的信息
- 时间序列切分不要随机打乱
- 改造后别忘了补一次端到端验证。

## 示例

```python
train = df[df.ts < cutoff]
valid = df[df.ts >= cutoff]
```

## 易错点

- 用全局统计量做标准化会造成泄漏

## 小结

特征穿越与数据泄漏 在落到真实场景的改造这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
