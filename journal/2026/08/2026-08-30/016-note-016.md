## 背景

## 要点

- 密钥不入库，使用环境注入或密钥服务
- 日志输出前统一脱敏，避免回过手来查泄漏
- 选型结论要写清前提，否则换个环境就不成立。

## 示例

```bash
token = os.environ['API_TOKEN']
log.info('using token %s', mask(token))
```

## 易错点

- 把密钥写进 URL 会进入访问日志

## 小结

配置管理中的密钥处理 在方案对比与选型这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
