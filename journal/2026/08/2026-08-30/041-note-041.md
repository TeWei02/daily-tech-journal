# 去重与近似的取舍：方案对比与选型

**日期**：2026-08-30　**领域**：数据　**编号**：41/115

## 背景

把候选方案的代价列清楚，选型就不再靠偏好。这里围绕「去重与近似的取舍」做一次整理，重点放在能直接落地的部分。

## 要点

- 精确去重占内存，HyperLogLog 误差可控但不可枚举
- 集合交并场景要注意误差叠加
- 选型结论要写清前提，否则换个环境就不成立。

## 示例

```python
from datasketch import HyperLogLog
hll = HyperLogLog(p=14)
```

## 易错点

- 对账场景不能使用近似算法

## 小结

去重与近似的取舍 在方案对比与选型这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
