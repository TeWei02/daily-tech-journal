# find 与 grep 的组合排查：调试与观测手法

**日期**：2026-08-30　**领域**：Linux　**编号**：79/115

## 背景

先拿到证据再改代码，日志与指标是第一手材料。这里围绕「find 与 grep 的组合排查」做一次整理，重点放在能直接落地的部分。

## 要点

- find 用 -print0 配合 xargs -0 处理含空格文件名
- grep -r 前先用 find 缩小范围能省大量 IO
- 把排查过程留成记录，下次能少走弯路。

## 示例

```bash
find . -name '*.log' -mtime -1 -print0 | xargs -0 grep -l ERROR
```

## 易错点

- xargs 默认按空白分割，遇到空格文件会断
