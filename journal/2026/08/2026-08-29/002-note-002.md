# 拓扑排序与入度表：边界条件与异常路径

**日期**：2026-08-29　**领域**：算法　**编号**：2/115

## 背景

空集合、极值、超时、部分失败，这几类最容易漏。这里围绕「拓扑排序与入度表」做一次整理，重点放在能直接落地的部分。

## 要点

- Kahn 算法逐层剥入度为零的点，天然给出分层信息
- 若结果长度小于节点数说明有环
- 边界用例应固化成自动化测试。

## 示例

```python
indeg = [0] * n
for u, v in edges:
    indeg[v] += 1
q = deque(i for i in range(n) if indeg[i] == 0)
```

## 易错点

- 有环时不要无限循环，需提前判断

## 小结

拓扑排序与入度表 在边界条件与异常路径这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
