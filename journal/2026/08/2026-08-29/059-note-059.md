# 幂等重试与退避：边界条件与异常路径

**日期**：2026-08-29　**领域**：系统　**编号**：59/115

## 背景

空集合、极值、超时、部分失败，这几类最容易漏。这里围绕「幂等重试与退避」做一次整理，重点放在能直接落地的部分。

## 要点

- 重试要区分可重试错误与业务失败
- 加入抖动避免同步重试造成脉冲
- 边界用例应固化成自动化测试。

## 示例

```python
delay = min(cap, base * 2 ** attempt) * random.uniform(0.8, 1.2)
```

## 易错点

- 对写接口无限重试会放大故障

## 小结

幂等重试与退避 在边界条件与异常路径这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
