# 堆在 Top-K 场景的应用：方案对比与选型

**日期**：2026-08-29　**领域**：算法　**编号**：89/115

## 背景

把候选方案的代价列清楚，选型就不再靠偏好。这里围绕「堆在 Top-K 场景的应用」做一次整理，重点放在能直接落地的部分。

## 要点

- 求最大 K 个用最小堆，堆大小维持 K，复杂度 O(n log K)
- Python heapq 是最小堆，取相反数实现最大堆
- 选型结论要写清前提，否则换个环境就不成立。

## 示例

```python
h = []
for x in nums:
    heappush(h, x)
    if len(h) > k:
        heappop(h)
```

## 易错点

- nlargest 在 K 很小时内部也会做优化，不必手写

## 小结

堆在 Top-K 场景的应用 在方案对比与选型这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
