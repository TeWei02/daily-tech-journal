# 并查集路径压缩与按秩合并：方案对比与选型

**日期**：2026-08-29　**领域**：算法　**编号**：87/115

## 背景

把候选方案的代价列清楚，选型就不再靠偏好。这里围绕「并查集路径压缩与按秩合并」做一次整理，重点放在能直接落地的部分。

## 要点

- find 递归写路径压缩，union 按秩合并保证树高近似对数
- 带权并查集需要在 find 中同步更新权值
- 选型结论要写清前提，否则换个环境就不成立。

## 示例

```python
def find(x):
    while x != p[x]:
        p[x] = p[p[x]]
        x = p[x]
    return x
```

## 易错点

- 只压缩不按秩合并也能均摊很优，但最坏情况退化

## 小结

并查集路径压缩与按秩合并 在方案对比与选型这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
