## 要点

- find 递归写路径压缩，union 按秩合并保证树高近似对数
- 带权并查集需要在 find 中同步更新权值
- 改造后别忘了补一次端到端验证。

## 示例

```python
def find(x):
    while x != p[x]:
        p[x] = p[p[x]]
        x = p[x]
    return x
```
