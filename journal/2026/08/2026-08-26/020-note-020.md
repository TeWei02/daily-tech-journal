# 事务隔离级别与幻读：实现原理与内部机制

**日期**：2026-08-26　**领域**：数据库　**编号**：20/115

## 背景

知道底层怎么走，行为异常时才能判断卡在哪一层。这里围绕「事务隔离级别与幻读」做一次整理，重点放在能直接落地的部分。

## 要点

- RR 下间隙锁可避免幻读，但会带来更多锁等待
- RC 下同一事务内两次读可能不一致
- 原理清楚后，参数上限与限制条件基本能自己推导。

## 示例

```sql
SET SESSION TRANSACTION ISOLATION LEVEL READ COMMITTED;
START TRANSACTION;
```

## 易错点

- 长事务会拖住 undo 清理，务必控制时长

## 小结

事务隔离级别与幻读 在实现原理与内部机制这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
