# ss 与 lsof 定位端口占用：落到真实场景的改造

**日期**：2026-08-26　**领域**：Linux　**编号**：95/115

## 背景

把它放进真实流程，通常要补上配置、日志与失败分支。这里围绕「ss 与 lsof 定位端口占用」做一次整理，重点放在能直接落地的部分。

## 要点

- ss -ltnp 比 netstat 更快且信息完整
- lsof -p 看到进程持有的全部 fd 与文件
- 改造后别忘了补一次端到端验证。

## 示例

```bash
ss -ltnp 'sport = :8080'
lsof -i :8080 -sTCP:LISTEN
```

## 易错点

- 容器内 ss 可能看不到宿主机命名空间的连接
