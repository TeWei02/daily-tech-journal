# SSRF 防御要点：实现原理与内部机制

**日期**：2026-08-26　**领域**：安全　**编号**：53/115

## 背景

知道底层怎么走，行为异常时才能判断卡在哪一层。这里围绕「SSRF 防御要点」做一次整理，重点放在能直接落地的部分。

## 要点

- 禁止访问内网段与元数据地址，解析后再校验 IP
- 重定向与 DNS 重绑定要一并考虑
- 原理清楚后，参数上限与限制条件基本能自己推导。

## 示例

```python
if ipaddress.ip_address(host).is_private: raise Reject()
```

## 易错点

- 只做字符串前缀过滤会被绕过

## 小结

SSRF 防御要点 在实现原理与内部机制这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
