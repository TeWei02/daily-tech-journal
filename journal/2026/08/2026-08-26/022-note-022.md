# 分页查询的深翻页优化：实现原理与内部机制

**日期**：2026-08-26　**领域**：数据库　**编号**：22/115

## 背景

知道底层怎么走，行为异常时才能判断卡在哪一层。这里围绕「分页查询的深翻页优化」做一次整理，重点放在能直接落地的部分。

## 要点

- LIMIT 大偏移量会扫描并丢弃前 N 行
- 游标分页用上一页最后一条的键做条件
- 原理清楚后，参数上限与限制条件基本能自己推导。

## 示例

```sql
SELECT * FROM t WHERE id > 100000 ORDER BY id LIMIT 20;
```

## 易错点

- 游标分页要求排序键唯一且稳定

## 小结

分页查询的深翻页优化 在实现原理与内部机制这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
