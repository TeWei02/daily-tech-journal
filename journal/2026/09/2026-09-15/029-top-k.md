# 堆在 Top-K 场景的应用：并发与线程安全

**日期**：2026-09-15　**领域**：算法　**编号**：29/114

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「堆在 Top-K 场景的应用」做一次整理，重点放在能直接落地的部分。

## 要点

- 求最大 K 个用最小堆，堆大小维持 K，复杂度 O(n log K)
- Python heapq 是最小堆，取相反数实现最大堆
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```python
h = []
for x in nums:
    heappush(h, x)
    if len(h) > k:
        heappop(h)
```

## 易错点

- nlargest 在 K 很小时内部也会做优化，不必手写

## 小结

堆在 Top-K 场景的应用 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
