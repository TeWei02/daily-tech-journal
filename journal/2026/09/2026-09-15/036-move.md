# move 语义与返回值优化：并发与线程安全

**日期**：2026-09-15　**领域**：C/C++　**编号**：36/114

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「move 语义与返回值优化」做一次整理，重点放在能直接落地的部分。

## 要点

- 返回局部对象优先依赖 NRVO，显式 move 反而阻止优化
- 被 move 后的对象处于有效但未指定状态，不要假设为空
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```cpp
std::vector<int> build() {
    std::vector<int> v;
    v.reserve(1024);
    return v;
}
```

## 易错点

- 对 const 对象 move 会退化成拷贝

## 小结

move 语义与返回值优化 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
