# 条件变量与虚假唤醒：并发与线程安全

**日期**：2026-09-15　**领域**：C/C++　**编号**：42/114

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「条件变量与虚假唤醒」做一次整理，重点放在能直接落地的部分。

## 要点

- wait 必须配谓词，否则会被虚假唤醒打穿
- 通知前先改状态并加锁，避免丢信号
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```cpp
std::unique_lock lk(m);
cv.wait(lk, [&]{ return !queue.empty(); });
auto job = std::move(queue.front()); queue.pop_front();
```

## 易错点

- notify 时若未持锁可能导致等待者错过判断

## 小结

条件变量与虚假唤醒 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
