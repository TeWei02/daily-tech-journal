# TLS 握手耗时拆解：并发与线程安全

**日期**：2026-09-15　**领域**：网络　**编号**：55/114

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「TLS 握手耗时拆解」做一次整理，重点放在能直接落地的部分。

## 要点

- 1-RTT 与 0-RTT 差异在会话复用，0-RTT 有重放风险
- 证书链不完整会导致部分客户端握手失败
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```bash
openssl s_client -connect host:443 -servername host -tls1_3
```

## 易错点

- SNI 缺失会拿到默认站点证书

## 小结

TLS 握手耗时拆解 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
