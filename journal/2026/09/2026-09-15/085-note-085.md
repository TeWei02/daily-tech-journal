# 熔断器状态机：并发与线程安全

**日期**：2026-09-15　**领域**：系统　**编号**：85/114

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「熔断器状态机」做一次整理，重点放在能直接落地的部分。

## 要点

- 关闭、打开、半开三态，半开只放少量探测流量
- 基于滑动窗口的失败率比连续失败计数更稳
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```python
if breaker.is_open():
    return fallback()
```

## 易错点

- 熔断恢复过快会导致反复抖动

## 小结

熔断器状态机 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
