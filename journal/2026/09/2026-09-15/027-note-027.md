# 并查集路径压缩与按秩合并：并发与线程安全

**日期**：2026-09-15　**领域**：算法　**编号**：27/114

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「并查集路径压缩与按秩合并」做一次整理，重点放在能直接落地的部分。

## 要点

- find 递归写路径压缩，union 按秩合并保证树高近似对数
- 带权并查集需要在 find 中同步更新权值
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```python
def find(x):
    while x != p[x]:
        p[x] = p[p[x]]
        x = p[x]
    return x
```

## 易错点

- 只压缩不按秩合并也能均摊很优，但最坏情况退化

## 小结

并查集路径压缩与按秩合并 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
