# Git 提交粒度与可回溯性：并发与线程安全

**日期**：2026-09-15　**领域**：工程　**编号**：67/114

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「Git 提交粒度与可回溯性」做一次整理，重点放在能直接落地的部分。

## 要点

- 一个提交只做一件事，便于 revert 与 bisect
- 提交信息写清动机而非仅描述改动
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```bash
git commit -m "fix(cache): 修正过期判断，避免负 TTL 被当作永不过期"
```

## 易错点

- 混合提交会让回滚牵连无关代码

## 小结

Git 提交粒度与可回溯性 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
