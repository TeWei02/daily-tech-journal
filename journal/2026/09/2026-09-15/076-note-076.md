# 表单校验的前后端分工：并发与线程安全

**日期**：2026-09-15　**领域**：Web　**编号**：76/114

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「表单校验的前后端分工」做一次整理，重点放在能直接落地的部分。

## 要点

- 前端校验提升体验，后端校验保证正确性，二者都要有
- 统一错误码便于前端映射提示文案
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```js
{ "code": "INVALID_EMAIL", "field": "email" }
```

## 易错点

- 只在后端校验会导致用户反复提交

## 小结

表单校验的前后端分工 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
