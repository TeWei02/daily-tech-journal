# const 正确性与重载：并发与线程安全

**日期**：2026-09-15　**领域**：C/C++　**编号**：38/114

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「const 正确性与重载」做一次整理，重点放在能直接落地的部分。

## 要点

- const 成员函数可被 const 对象调用，mutable 允许修改缓存字段
- 按值返回 const 会阻止移动语义
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```cpp
int cached() const { return cache_; }
void update() { cache_ = compute(); }
```

## 易错点

- 为 const 与非 const 各写一份容易重复，用泛型辅助

## 小结

const 正确性与重载 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
