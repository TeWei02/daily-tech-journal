# 滑动窗口求最长子串：与相邻技术的配合

## 背景

它很少单独出现，和上下游的约定决定了整体效果。这里围绕「滑动窗口求最长子串」做一次整理，重点放在能直接落地的部分。

## 要点

- 窗口右移扩张、左移收缩，每次收缩后检查条件
- 出现次数用数组或哈希表，注意清理零计数键
- 跨组件问题先在边界处抓包或打日志。

## 示例

```python
cnt = {}
l = best = 0
for r, ch in enumerate(s):
    cnt[ch] = cnt.get(ch, 0) + 1
    while cnt[ch] > 1:
        cnt[s[l]] -= 1
        l += 1
    best = max(best, r - l + 1)
```

## 易错点

- 条件写成 while 而非 if，否则窗口收缩不彻底

## 小结

滑动窗口求最长子串 在与相邻技术的配合这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
