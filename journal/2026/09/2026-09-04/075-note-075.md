# 分布式锁的续约与释放：配置与参数调优

**日期**：2026-09-04　**领域**：并发　**编号**：75/115

## 背景

参数调整必须一次只改一个，否则无法归因。这里围绕「分布式锁的续约与释放」做一次整理，重点放在能直接落地的部分。

## 要点

- 锁需带唯一值以便安全释放，避免删掉他人的锁
- 业务耗时长于租约要续约，续约失败应尽快中止
- 调优结论要绑定当时的负载特征。

## 示例

```cpp
SET lock:job 7f3a NX PX 30000
```

## 易错点

- 用固定值做锁会导致误删

## 小结

分布式锁的续约与释放 在配置与参数调优这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
