# 单调栈求下一个更大元素：配置与参数调优

**日期**：2026-09-04　**领域**：算法　**编号**：21/115

## 背景

参数调整必须一次只改一个，否则无法归因。这里围绕「单调栈求下一个更大元素」做一次整理，重点放在能直接落地的部分。

## 要点

- 栈内维护递减序列，弹出时即确定右侧第一个更大值
- 循环数组需要遍历两遍并取模
- 调优结论要绑定当时的负载特征。

## 示例

```python
stack = []
res = [0] * n
for i, x in enumerate(a):
    while stack and a[stack[-1]] < x:
        res[stack.pop()] = x
    stack.append(i)
```

## 易错点

- 忘记把未弹出的下标置为 -1 会留下默认值

## 小结

单调栈求下一个更大元素 在配置与参数调优这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
