# 限流的三种实现：配置与参数调优

**日期**：2026-09-04　**领域**：系统　**编号**：77/115

## 背景

参数调整必须一次只改一个，否则无法归因。这里围绕「限流的三种实现」做一次整理，重点放在能直接落地的部分。

## 要点

- 计数器简单但有临界问题，漏桶平滑输出，令牌桶允许突发
- 限流维度要能被业务理解，如按用户或按租户
- 调优结论要绑定当时的负载特征。

## 示例

```python
allow = token_bucket.try_acquire(cost=1)
if not allow:
    return Response(429, headers={'Retry-After': '1'})
```

## 易错点

- 全局限流和单机限流混用会导致实际配额翻倍

## 小结

限流的三种实现 在配置与参数调优这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
