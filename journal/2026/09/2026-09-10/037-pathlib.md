# pathlib 路径操作：常见陷阱与错误示范

**日期**：2026-09-10　**领域**：Python　**编号**：37/99

## 背景

多数线上问题不是不会用，而是用错了一个细节。这里围绕「pathlib 路径操作」做一次整理，重点放在能直接落地的部分。

## 要点

- Path 是不可变对象，所有操作返回新对象
- resolve() 会展开符号链接并规范化大小写
- 把踩过的坑写成检查项，比背结论更有效。

## 示例

```python
root = Path('data').resolve()
for p in root.rglob('*.csv'):
    handle(p.with_suffix('.parquet'))
```

## 易错点

- 不要用字符串拼接路径，跨平台会出错

pathlib 路径操作 在常见陷阱与错误示范这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
