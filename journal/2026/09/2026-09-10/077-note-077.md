# 分页查询的深翻页优化：常见陷阱与错误示范

**日期**：2026-09-10　**领域**：数据库　**编号**：77/99

## 背景

多数线上问题不是不会用，而是用错了一个细节。这里围绕「分页查询的深翻页优化」做一次整理，重点放在能直接落地的部分。

## 要点

- LIMIT 大偏移量会扫描并丢弃前 N 行
- 游标分页用上一页最后一条的键做条件
- 把踩过的坑写成检查项，比背结论更有效。

## 示例

```sql
SELECT * FROM t WHERE id > 100000 ORDER BY id LIMIT 20;
```

## 易错点

- 游标分页要求排序键唯一且稳定

## 小结

分页查询的深翻页优化 在常见陷阱与错误示范这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
