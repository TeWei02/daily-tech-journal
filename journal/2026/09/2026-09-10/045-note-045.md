# 动态规划的滚动数组优化：常见陷阱与错误示范

**日期**：2026-09-10　**领域**：算法　**编号**：45/99

## 背景

多数线上问题不是不会用，而是用错了一个细节。这里围绕「动态规划的滚动数组优化」做一次整理，重点放在能直接落地的部分。

## 要点

- 状态只依赖前一层时，倒序更新可把二维压成一维
- 0-1 背包倒序，完全背包正序
- 把踩过的坑写成检查项，比背结论更有效。

## 示例

```python
dp = [0] * (cap + 1)
for w, v in items:
    for c in range(cap, w - 1, -1):
        dp[c] = max(dp[c], dp[c - w] + v)
```

## 易错点

- 正序更新会让同一物品被重复使用

## 小结

动态规划的滚动数组优化 在常见陷阱与错误示范这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
