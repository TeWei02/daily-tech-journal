# pathlib 路径操作：实现原理与内部机制

**日期**：2026-09-08　**领域**：Python　**编号**：89/115

## 背景

知道底层怎么走，行为异常时才能判断卡在哪一层。这里围绕「pathlib 路径操作」做一次整理，重点放在能直接落地的部分。

## 要点

- Path 是不可变对象，所有操作返回新对象
- resolve() 会展开符号链接并规范化大小写
- 原理清楚后，参数上限与限制条件基本能自己推导。

## 示例

```python
root = Path('data').resolve()
for p in root.rglob('*.csv'):
    handle(p.with_suffix('.parquet'))
```

## 易错点

- 不要用字符串拼接路径，跨平台会出错

## 小结

pathlib 路径操作 在实现原理与内部机制这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
