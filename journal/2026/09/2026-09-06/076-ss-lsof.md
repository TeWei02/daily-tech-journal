# ss 与 lsof 定位端口占用：小规模验证方法

**日期**：2026-09-06　**领域**：Linux　**编号**：76/115

## 背景

先用小样本验证假设，再决定是否推广。这里围绕「ss 与 lsof 定位端口占用」做一次整理，重点放在能直接落地的部分。

## 要点

- ss -ltnp 比 netstat 更快且信息完整
- lsof -p 看到进程持有的全部 fd 与文件
- 试点结论要能复现。

## 示例

```bash
ss -ltnp 'sport = :8080'
lsof -i :8080 -sTCP:LISTEN
```

## 易错点

- 容器内 ss 可能看不到宿主机命名空间的连接

## 小结

ss 与 lsof 定位端口占用 在小规模验证方法这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
