# 可观测性三支柱关联：代价与适用边界

**日期**：2026-09-06　**领域**：工具　**编号**：43/115

## 背景

任何方案都有不适用的时候，提前写清楚。这里围绕「可观测性三支柱关联」做一次整理，重点放在能直接落地的部分。

## 要点

- 用 trace id 把日志、指标、链路串起来
- 指标看趋势，链路看个案，日志看细节
- 把不适用条件写进文档，避免误用。

## 示例

```yaml
log.info('order ok', extra={'trace': trace_id})
```

## 易错点

- 缺少 trace 关联会让排障退化为翻日志

## 小结

可观测性三支柱关联 在代价与适用边界这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
