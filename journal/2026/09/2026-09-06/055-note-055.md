# 二分查找的三种边界写法：小规模验证方法

**日期**：2026-09-06　**领域**：算法　**编号**：55/115

## 背景

先用小样本验证假设，再决定是否推广。这里围绕「二分查找的三种边界写法」做一次整理，重点放在能直接落地的部分。

## 要点

- 闭区间写法 lo<=hi，左闭右开写法 lo<hi，混用会导致死循环
- 求下界用 lower_bound，避免返回命中即返回
- 试点结论要能复现。

## 示例

```python
lo, hi = 0, len(a)
while lo < hi:
    mid = (lo + hi) // 2
    if a[mid] < target:
        lo = mid + 1
    else:
        hi = mid
return lo
```

## 易错点

- mid 计算用 lo+(hi-lo)//2 可避免整型溢出

## 小结

二分查找的三种边界写法 在小规模验证方法这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
