# 分页查询的深翻页优化：代价与适用边界

**日期**：2026-09-06　**领域**：数据库　**编号**：3/115

## 背景

任何方案都有不适用的时候，提前写清楚。这里围绕「分页查询的深翻页优化」做一次整理，重点放在能直接落地的部分。

## 要点

- LIMIT 大偏移量会扫描并丢弃前 N 行
- 游标分页用上一页最后一条的键做条件
- 把不适用条件写进文档，避免误用。

## 示例

```sql
SELECT * FROM t WHERE id > 100000 ORDER BY id LIMIT 20;
```

## 易错点

- 游标分页要求排序键唯一且稳定
