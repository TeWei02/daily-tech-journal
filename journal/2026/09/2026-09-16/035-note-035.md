# 权限位与 ACL 的叠加：测试与验证策略

**日期**：2026-09-16　**领域**：Linux　**编号**：35/115

## 背景

测试要覆盖正常、边界与失败三类路径。这里围绕「权限位与 ACL 的叠加」做一次整理，重点放在能直接落地的部分。

## 要点

- 目录的 x 位决定能否进入，读目录内容需要 r
- ACL 生效后 group 权限会显示为 mask
- 测试用例本身也要可维护。

## 示例

```bash
setfacl -m u:deploy:rx /srv/app
getfacl /srv/app
```

## 易错点

- umask 会影响新建文件，但不会回收已有权限

## 小结

权限位与 ACL 的叠加 在测试与验证策略这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
