# const 正确性与重载：重构与可维护性

**日期**：2026-09-16　**领域**：C/C++　**编号**：112/115

## 背景

先把行为固定住再改结构，避免同时改两件事。这里围绕「const 正确性与重载」做一次整理，重点放在能直接落地的部分。

## 要点

- const 成员函数可被 const 对象调用，mutable 允许修改缓存字段
- 按值返回 const 会阻止移动语义
- 重构后接口不变，调用方无感。

## 示例

```cpp
int cached() const { return cache_; }
void update() { cache_ = compute(); }
```

## 易错点

- 为 const 与非 const 各写一份容易重复，用泛型辅助
