# SSRF 防御要点：测试与验证策略

**日期**：2026-09-16　**领域**：安全　**编号**：78/115

## 背景

测试要覆盖正常、边界与失败三类路径。这里围绕「SSRF 防御要点」做一次整理，重点放在能直接落地的部分。

## 要点

- 禁止访问内网段与元数据地址，解析后再校验 IP
- 重定向与 DNS 重绑定要一并考虑
- 测试用例本身也要可维护。

## 示例

```python
if ipaddress.ip_address(host).is_private: raise Reject()
```

## 易错点

- 只做字符串前缀过滤会被绕过

## 小结

SSRF 防御要点 在测试与验证策略这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
