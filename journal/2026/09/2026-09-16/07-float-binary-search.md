# 浮点数二分与精度控制

**日期**：2026-09-16　**领域**：算法与数据结构　**系列**：二分查找与边界处理 · 第 7 则

## 学习目标

处理实数域上的二分，避免精度与死循环问题。

## 核心要点

- 固定迭代次数比 while hi - lo > eps 更稳定，通常 100 次足够。
- eps 设置过小会因浮点表示误差导致死循环。
- 涉及平方根、方程求解时，注意初始区间的选取要包含所有解。

## 示例

```python
for _ in range(100):
    mid = (lo + hi) / 2
    if mid * mid < n:
        lo = mid
    else:
        hi = mid
```

## 易错点

- 用等号判断浮点相等几乎总是错的，应该比较区间宽度。

## 小结

浮点二分用固定迭代次数最省心。
