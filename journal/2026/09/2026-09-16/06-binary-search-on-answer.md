# 二分答案：把最优化问题转成判定问题

**日期**：2026-09-16　**领域**：算法与数据结构　**系列**：二分查找与边界处理

## 一句话说明

掌握二分答案的适用条件与套路。

## 关键点

- 当答案具有单调性时，可以二分答案并检验可行性。
- 核心是写出 check(x)：给定候选值判断是否满足约束。
- 答案为整数时用整数二分，注意取整方向与收缩方式相匹配。

## 代码 / 命令

```python
def solve():
    lo, hi = 0, max_value
    while lo < hi:
        mid = (lo + hi) // 2
        if check(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

## 注意事项

- check 函数不满足单调性时二分答案会给出错误结果，务必先验证性质。

## 小结

二分答案把求解变判定，是竞赛与面试中的高频套路。
