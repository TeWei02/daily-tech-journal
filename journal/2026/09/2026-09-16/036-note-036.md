# TCP 三次握手与半连接队列：测试与验证策略

**日期**：2026-09-16　**领域**：网络　**编号**：36/115

## 背景

测试要覆盖正常、边界与失败三类路径。这里围绕「TCP 三次握手与半连接队列」做一次整理，重点放在能直接落地的部分。

## 要点

- SYN 队列与 accept 队列分离，溢出时按 tcp_abort_on_overflow 决定行为
- syncookies 可在半连接溢出时继续服务但牺牲部分选项
- 测试用例本身也要可维护。

## 示例

```bash
ss -lnt
# Recv-Q 为当前 accept 队列长度，Send-Q 为 backlog 上限
```

## 易错点

- backlog 调大不等于能扛住 SYN Flood，需要内核参数配合

## 小结

TCP 三次握手与半连接队列 在测试与验证策略这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
