# 旋转有序数组中的查找

**日期**：2026-09-16　**领域**：算法与数据结构　**系列**：二分查找与边界处理 · 第 5 则

## 学习目标

在有断点的有序数组中仍然做到对数时间。

## 核心要点

- 旋转后数组由两段有序区间构成，二分时先判断哪一半是有序的。
- 若左半有序且 target 落在左半区间内，则收缩到左半，否则进入右半。
- 数组中存在重复元素时最坏会退化到 O(n)。

## 示例

```python
if nums[lo] <= nums[mid]:
    if nums[lo] <= target < nums[mid]:
        hi = mid - 1
    else:
        lo = mid + 1
```

## 易错点

- 比较时忽略等号，会在只剩两个元素时漏判。

## 小结

先判断有序区间，再判断目标是否落在其中。
