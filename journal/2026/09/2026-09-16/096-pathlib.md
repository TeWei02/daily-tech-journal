# pathlib 路径操作：重构与可维护性

**日期**：2026-09-16　**领域**：Python　**编号**：96/115

## 背景

先把行为固定住再改结构，避免同时改两件事。这里围绕「pathlib 路径操作」做一次整理，重点放在能直接落地的部分。

## 要点

- Path 是不可变对象，所有操作返回新对象
- resolve() 会展开符号链接并规范化大小写
- 重构后接口不变，调用方无感。

## 示例

```python
root = Path('data').resolve()
for p in root.rglob('*.csv'):
    handle(p.with_suffix('.parquet'))
```

## 易错点

- 不要用字符串拼接路径，跨平台会出错

## 小结

pathlib 路径操作 在重构与可维护性这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
