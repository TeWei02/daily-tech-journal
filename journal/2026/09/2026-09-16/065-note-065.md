# 协程调度与阻塞调用：测试与验证策略

**日期**：2026-09-16　**领域**：并发　**编号**：65/115

## 背景

测试要覆盖正常、边界与失败三类路径。这里围绕「协程调度与阻塞调用」做一次整理，重点放在能直接落地的部分。

## 要点

- 在事件循环中做同步 IO 会阻塞所有协程，需放入线程池
- CPU 密集任务同样需要外移
- 测试用例本身也要可维护。

## 示例

```cpp
await asyncio.to_thread(requests.get, url, timeout=3)
```

## 易错点

- sleep 必须用 asyncio.sleep，time.sleep 会卡住循环

## 小结

协程调度与阻塞调用 在测试与验证策略这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
