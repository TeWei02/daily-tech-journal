# 堆在 Top-K 场景的应用：重构与可维护性

**日期**：2026-09-16　**领域**：算法　**编号**：103/115

## 背景

先把行为固定住再改结构，避免同时改两件事。这里围绕「堆在 Top-K 场景的应用」做一次整理，重点放在能直接落地的部分。

## 要点

- 求最大 K 个用最小堆，堆大小维持 K，复杂度 O(n log K)
- Python heapq 是最小堆，取相反数实现最大堆
- 重构后接口不变，调用方无感。

## 示例

```python
h = []
for x in nums:
    heappush(h, x)
    if len(h) > k:
        heappop(h)
```

## 易错点

- nlargest 在 K 很小时内部也会做优化，不必手写
