# 左闭右闭与左闭右开

**日期**：2026-09-16　**领域**：算法与数据结构　**系列**：二分查找与边界处理

## 一句话说明

掌握两种区间风格的转换，避免混用导致的死循环。

## 关键点

- 左闭右闭写 hi = n - 1，循环条件 lo <= hi，收缩时 hi = mid - 1。
- 左闭右开写 hi = n，循环条件 lo < hi，收缩时 hi = mid。
- 两种风格本身都正确，错误来自混用，例如区间是右开却写 hi = mid - 1。

## 代码 / 命令

```python
lo, hi = 0, len(nums)
while lo < hi:
    mid = (lo + hi) // 2
    if nums[mid] < target:
        lo = mid + 1
    else:
        hi = mid
```

## 注意事项

- 区间语义与循环条件不匹配是死循环的头号原因。

## 小结

先声明区间语义，再写循环条件。
