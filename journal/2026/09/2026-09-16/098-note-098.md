# 序列化性能与安全性：重构与可维护性

**日期**：2026-09-16　**领域**：Python　**编号**：98/115

## 背景

先把行为固定住再改结构，避免同时改两件事。这里围绕「序列化性能与安全性」做一次整理，重点放在能直接落地的部分。

## 要点

- pickle 反序列化不可信数据等于执行任意代码
- 跨语言场景用 JSON 或 msgpack，注意浮点与时间精度
- 重构后接口不变，调用方无感。

## 示例

```python
import json
payload = json.dumps(rec, ensure_ascii=False, separators=(',', ':'))
```

## 易错点

- 默认 ensure_ascii=True 会让中文体积翻三倍

## 小结

序列化性能与安全性 在重构与可维护性这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
