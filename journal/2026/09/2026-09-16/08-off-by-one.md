# 二分查找的典型越界与死循环

**日期**：2026-09-16　**领域**：算法与数据结构　**系列**：二分查找与边界处理

## 一句话说明

总结实战中最容易踩的坑。

## 关键点

- hi 初始值取 n 还是 n-1 必须与循环条件一致。
- mid 不前进是死循环的常见原因，要确保每次迭代区间严格缩小。
- 只剩两个元素时是 bug 高发区，测试用例应专门覆盖。

## 代码 / 命令

```python
# 死循环示例：区间不缩小
while lo < hi:
    mid = (lo + hi) // 2
    if ok(mid):
        lo = mid   # 当 hi == lo + 1 时 mid == lo，区间不变
```

## 注意事项

- 边界用例只写一个元素、两个元素往往就能暴露问题。

## 小结

二分写完后先拿长度 1、2 的数组验一遍。
