# pathlib 路径操作：性能与复杂度权衡

**日期**：2026-09-11　**领域**：Python　**编号**：27/115

## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「pathlib 路径操作」做一次整理，重点放在能直接落地的部分。

## 要点

- Path 是不可变对象，所有操作返回新对象
- resolve() 会展开符号链接并规范化大小写
- 优化前后都要有可复现的基准数据。

## 示例

```python
root = Path('data').resolve()
for p in root.rglob('*.csv'):
    handle(p.with_suffix('.parquet'))
```

## 易错点

- 不要用字符串拼接路径，跨平台会出错

## 小结

pathlib 路径操作 在性能与复杂度权衡这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
