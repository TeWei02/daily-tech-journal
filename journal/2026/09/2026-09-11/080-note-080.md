## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「状态管理的单一数据源」做一次整理，重点放在能直接落地的部分。

## 要点

- 派生状态不要重复存储，否则需要同步逻辑
- 异步状态用显式的加载与错误枚举表示
- 优化前后都要有可复现的基准数据。

## 示例

```js
const rows = computed(() => items.filter(i => i.ok))
```

## 易错点

- 把加载状态散落各处会导致界面闪烁

## 小结

状态管理的单一数据源 在性能与复杂度权衡这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
