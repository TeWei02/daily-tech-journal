# JWT 校验的必查项：性能与复杂度权衡

**日期**：2026-09-11　**领域**：安全　**编号**：97/115

## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「JWT 校验的必查项」做一次整理，重点放在能直接落地的部分。

## 要点

- 校验签名算法、签发者、受众与过期时间
- 不要信任未校验的头部信息
- 优化前后都要有可复现的基准数据。

## 示例

```python
jwt.decode(token, key, algorithms=['RS256'], audience='api')
```

## 易错点

- 接受 alg=none 是经典漏洞

## 小结

JWT 校验的必查项 在性能与复杂度权衡这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
