# 无锁队列的 ABA 问题：性能与复杂度权衡

**日期**：2026-09-11　**领域**：并发　**编号**：83/115

## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「无锁队列的 ABA 问题」做一次整理，重点放在能直接落地的部分。

## 要点

- 比较并交换需要版本号或标签位才能识别 ABA
- 内存回收（如 RCU、引用计数）与无锁结构必须一起设计
- 优化前后都要有可复现的基准数据。

## 示例

```cpp
bool push(Node* n) {
  Node* head = head_.load();
  n->next = head;
  return head_.compare_exchange_weak(head, n);
}
```

## 易错点

- 在 C++ 中用 std::atomic<Node*> 直接 CAS 存在内存回收风险

## 小结

无锁队列的 ABA 问题 在性能与复杂度权衡这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
