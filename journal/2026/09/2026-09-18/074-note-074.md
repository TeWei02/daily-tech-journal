# 条件变量与虚假唤醒：配置与参数调优

**日期**：2026-09-18　**领域**：C/C++　**编号**：74/115

## 背景

参数调整必须一次只改一个，否则无法归因。这里围绕「条件变量与虚假唤醒」做一次整理，重点放在能直接落地的部分。

## 要点

- wait 必须配谓词，否则会被虚假唤醒打穿
- 通知前先改状态并加锁，避免丢信号
- 调优结论要绑定当时的负载特征。

## 示例

```cpp
std::unique_lock lk(m);
cv.wait(lk, [&]{ return !queue.empty(); });
auto job = std::move(queue.front()); queue.pop_front();
```

## 易错点

- notify 时若未持锁可能导致等待者错过判断

## 小结

条件变量与虚假唤醒 在配置与参数调优这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
