**日期**：2026-09-18　**领域**：数据库　**编号**：5/115

## 背景

复盘只谈事实与改进项，不追责个人。这里围绕「分页查询的深翻页优化」做一次整理，重点放在能直接落地的部分。

## 要点

- LIMIT 大偏移量会扫描并丢弃前 N 行
- 游标分页用上一页最后一条的键做条件
- 每个改进项都要有负责人与截止时间。

## 示例

```sql
SELECT * FROM t WHERE id > 100000 ORDER BY id LIMIT 20;
```

## 易错点

- 游标分页要求排序键唯一且稳定
