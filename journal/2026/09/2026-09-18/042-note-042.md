# 容器镜像瘦身：线上问题复盘

**日期**：2026-09-18　**领域**：工具　**编号**：42/115

## 背景

复盘只谈事实与改进项，不追责个人。这里围绕「容器镜像瘦身」做一次整理，重点放在能直接落地的部分。

## 要点

- 多阶段构建把编译工具留在中间层
- 注意层缓存顺序，把变动少的指令前置
- 每个改进项都要有负责人与截止时间。

## 示例

```yaml
FROM golang:1.22 AS build
RUN go build -o /app .
FROM gcr.io/distroless/base
COPY --from=build /app /app
```

## 易错点

- 把 .git 与测试数据打进镜像会显著增大体积

## 小结

容器镜像瘦身 在线上问题复盘这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
