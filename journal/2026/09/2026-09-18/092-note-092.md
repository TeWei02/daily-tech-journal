# 事务隔离级别与幻读：配置与参数调优

**日期**：2026-09-18　**领域**：数据库　**编号**：92/115

## 背景

参数调整必须一次只改一个，否则无法归因。这里围绕「事务隔离级别与幻读」做一次整理，重点放在能直接落地的部分。

## 要点

- RR 下间隙锁可避免幻读，但会带来更多锁等待
- RC 下同一事务内两次读可能不一致
- 调优结论要绑定当时的负载特征。

## 示例

```sql
SET SESSION TRANSACTION ISOLATION LEVEL READ COMMITTED;
START TRANSACTION;
```

## 易错点

- 长事务会拖住 undo 清理，务必控制时长

## 小结

事务隔离级别与幻读 在配置与参数调优这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
