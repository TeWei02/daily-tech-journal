# 拓扑排序与入度表：配置与参数调优

**日期**：2026-09-18　**领域**：算法　**编号**：63/115

## 背景

参数调整必须一次只改一个，否则无法归因。这里围绕「拓扑排序与入度表」做一次整理，重点放在能直接落地的部分。

## 要点

- Kahn 算法逐层剥入度为零的点，天然给出分层信息
- 若结果长度小于节点数说明有环
- 调优结论要绑定当时的负载特征。

## 示例

```python
indeg = [0] * n
for u, v in edges:
    indeg[v] += 1
q = deque(i for i in range(n) if indeg[i] == 0)
```

## 易错点

- 有环时不要无限循环，需提前判断

## 小结

拓扑排序与入度表 在配置与参数调优这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
