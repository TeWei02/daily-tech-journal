# 表单校验的前后端分工：线上问题复盘

**日期**：2026-09-03　**领域**：Web　**编号**：95/115

## 背景

复盘只谈事实与改进项，不追责个人。这里围绕「表单校验的前后端分工」做一次整理，重点放在能直接落地的部分。

## 要点

- 前端校验提升体验，后端校验保证正确性，二者都要有
- 统一错误码便于前端映射提示文案
- 每个改进项都要有负责人与截止时间。

## 示例

```js
{ "code": "INVALID_EMAIL", "field": "email" }
```

## 易错点

- 只在后端校验会导致用户反复提交

## 小结

表单校验的前后端分工 在线上问题复盘这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
