# 连接复用与 keep-alive 调优：线上问题复盘

**日期**：2026-09-03　**领域**：网络　**编号**：75/115

## 背景

复盘只谈事实与改进项，不追责个人。这里围绕「连接复用与 keep-alive 调优」做一次整理，重点放在能直接落地的部分。

## 要点

- 空闲连接会被中间设备静默断开，客户端应设略小于服务端的超时
- 连接池过大会挤占内存，过小会增加握手开销
- 每个改进项都要有负责人与截止时间。

## 示例

```bash
requests.Session()
adapter = HTTPAdapter(pool_connections=32, pool_maxsize=64)
```

## 易错点

- NAT 超时通常 300 秒左右，不宜设置过长

## 小结

连接复用与 keep-alive 调优 在线上问题复盘这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
