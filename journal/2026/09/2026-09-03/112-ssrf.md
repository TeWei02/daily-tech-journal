## 背景

复盘只谈事实与改进项，不追责个人。这里围绕「SSRF 防御要点」做一次整理，重点放在能直接落地的部分。

## 要点

- 禁止访问内网段与元数据地址，解析后再校验 IP
- 重定向与 DNS 重绑定要一并考虑
- 每个改进项都要有负责人与截止时间。

## 示例

```python
if ipaddress.ip_address(host).is_private: raise Reject()
```

## 易错点
