# 双指针处理有序数组去重：线上问题复盘

**日期**：2026-09-03　**领域**：算法　**编号**：52/115

## 背景

复盘只谈事实与改进项，不追责个人。这里围绕「双指针处理有序数组去重」做一次整理，重点放在能直接落地的部分。

## 要点

- 快慢指针原地覆盖，慢指针指向已确定的最后一个合法位置
- 返回长度而非新数组，调用方只读前 k 个
- 每个改进项都要有负责人与截止时间。

## 示例

```python
k = 0
for x in a:
    if k == 0 or x != a[k - 1]:
        a[k] = x
        k += 1
```

## 易错点

- 比较对象是已写入的值而不是原数组前一位
