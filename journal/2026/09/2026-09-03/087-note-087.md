# 分支策略与长期分支风险：线上问题复盘

**日期**：2026-09-03　**领域**：工程　**编号**：87/115

## 背景

复盘只谈事实与改进项，不追责个人。这里围绕「分支策略与长期分支风险」做一次整理，重点放在能直接落地的部分。

## 要点

- 长期分支合并回主干的冲突成本随时间线性增长
- 短分支 + 频繁集成能显著降低合并风险
- 每个改进项都要有负责人与截止时间。

## 示例

```bash
git fetch origin
git rebase origin/main
```

## 易错点

- 对已推送的公共分支 rebase 会改写他人历史

## 小结

分支策略与长期分支风险 在线上问题复盘这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
