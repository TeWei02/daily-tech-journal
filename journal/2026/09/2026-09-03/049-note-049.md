# 动态规划的滚动数组优化：线上问题复盘

**日期**：2026-09-03　**领域**：算法　**编号**：49/115

## 背景

复盘只谈事实与改进项，不追责个人。这里围绕「动态规划的滚动数组优化」做一次整理，重点放在能直接落地的部分。

## 要点

- 状态只依赖前一层时，倒序更新可把二维压成一维
- 0-1 背包倒序，完全背包正序
- 每个改进项都要有负责人与截止时间。

## 示例

```python
dp = [0] * (cap + 1)
for w, v in items:
    for c in range(cap, w - 1, -1):
        dp[c] = max(dp[c], dp[c - w] + v)
```

## 易错点

- 正序更新会让同一物品被重复使用

## 小结

动态规划的滚动数组优化 在线上问题复盘这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
