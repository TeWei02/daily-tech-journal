# const 正确性与重载：边界条件与异常路径

**日期**：2026-09-12　**领域**：C/C++　**编号**：17/115

## 背景

空集合、极值、超时、部分失败，这几类最容易漏。这里围绕「const 正确性与重载」做一次整理，重点放在能直接落地的部分。

## 要点

- const 成员函数可被 const 对象调用，mutable 允许修改缓存字段
- 按值返回 const 会阻止移动语义
- 边界用例应固化成自动化测试。

## 示例

```cpp
int cached() const { return cache_; }
void update() { cache_ = compute(); }
```

## 易错点

- 为 const 与非 const 各写一份容易重复，用泛型辅助

## 小结

const 正确性与重载 在边界条件与异常路径这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
