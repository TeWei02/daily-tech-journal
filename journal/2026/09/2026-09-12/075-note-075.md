# 去重与近似的取舍：边界条件与异常路径

**日期**：2026-09-12　**领域**：数据　**编号**：75/115

## 背景

空集合、极值、超时、部分失败，这几类最容易漏。这里围绕「去重与近似的取舍」做一次整理，重点放在能直接落地的部分。

## 要点

- 精确去重占内存，HyperLogLog 误差可控但不可枚举
- 集合交并场景要注意误差叠加
- 边界用例应固化成自动化测试。

## 示例

```python
from datasketch import HyperLogLog
hll = HyperLogLog(p=14)
```

## 易错点

- 对账场景不能使用近似算法

## 小结

去重与近似的取舍 在边界条件与异常路径这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
