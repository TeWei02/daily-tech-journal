# 堆在 Top-K 场景的应用：线上问题复盘

**日期**：2026-09-17　**领域**：算法　**编号**：87/115

## 背景

复盘只谈事实与改进项，不追责个人。这里围绕「堆在 Top-K 场景的应用」做一次整理，重点放在能直接落地的部分。

## 要点

- 求最大 K 个用最小堆，堆大小维持 K，复杂度 O(n log K)
- Python heapq 是最小堆，取相反数实现最大堆
- 每个改进项都要有负责人与截止时间。

## 示例

```python
h = []
for x in nums:
    heappush(h, x)
    if len(h) > k:
        heappop(h)
```

## 易错点

- nlargest 在 K 很小时内部也会做优化，不必手写
