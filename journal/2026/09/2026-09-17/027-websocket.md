# WebSocket 心跳与重连：重构与可维护性

**日期**：2026-09-17　**领域**：网络　**编号**：27/115

## 背景

先把行为固定住再改结构，避免同时改两件事。这里围绕「WebSocket 心跳与重连」做一次整理，重点放在能直接落地的部分。

## 要点

- 应用层心跳可穿过多数代理，需与服务端 idle 超时配合
- 重连要带指数退避与抖动，避免雪崩
- 重构后接口不变，调用方无感。

## 示例

```bash
async def heartbeat(ws):
    while True:
        await asyncio.sleep(20)
        await ws.send(b'{"t":"ping"}')
```

## 易错点

- 只在 onclose 里重连会漏掉半开连接

## 小结

WebSocket 心跳与重连 在重构与可维护性这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
