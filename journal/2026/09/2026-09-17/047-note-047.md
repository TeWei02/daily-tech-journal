## 背景

先把行为固定住再改结构，避免同时改两件事。这里围绕「无锁队列的 ABA 问题」做一次整理，重点放在能直接落地的部分。

## 要点

- 比较并交换需要版本号或标签位才能识别 ABA
- 内存回收（如 RCU、引用计数）与无锁结构必须一起设计
- 重构后接口不变，调用方无感。

## 示例

```cpp
bool push(Node* n) {
  Node* head = head_.load();
  n->next = head;
  return head_.compare_exchange_weak(head, n);
}
```

## 易错点

- 在 C++ 中用 std::atomic<Node*> 直接 CAS 存在内存回收风险
