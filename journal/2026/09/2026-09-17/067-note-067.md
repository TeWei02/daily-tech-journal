# 特征穿越与数据泄漏：重构与可维护性

**日期**：2026-09-17　**领域**：数据　**编号**：67/115

## 背景

先把行为固定住再改结构，避免同时改两件事。这里围绕「特征穿越与数据泄漏」做一次整理，重点放在能直接落地的部分。

## 要点

- 训练特征只能使用预测时刻之前可获得的信息
- 时间序列切分不要随机打乱
- 重构后接口不变，调用方无感。

## 示例

```python
train = df[df.ts < cutoff]
valid = df[df.ts >= cutoff]
```

## 易错点

- 用全局统计量做标准化会造成泄漏

## 小结

特征穿越与数据泄漏 在重构与可维护性这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
