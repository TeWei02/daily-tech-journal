# 定时任务：cron 与 systemd timer

**日期**：2026-09-17　**领域**：Linux 与工程实践　**系列**：Linux 命令行与 Shell

## 一句话说明

选择合适的定时方案并会排查未执行问题。

## 关键点

- cron 表达式依次为分、时、日、月、星期，*/5 表示每 5 个单位。
- cron 环境变量极简，脚本里要用绝对路径或显式加载环境。
- systemd timer 支持日志与依赖管理，适合服务化场景。

## 代码 / 命令

```bash
crontab -l
# 每 5 分钟执行一次
*/5 * * * * /usr/local/bin/backup.sh >> /var/log/backup.log 2>&1
```

## 注意事项

- 任务没执行先看日志与 PATH，多数问题是环境变量缺失。

## 小结

定时任务要留日志，否则失败无从查起。
