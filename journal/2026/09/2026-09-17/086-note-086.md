# 单调栈求下一个更大元素：线上问题复盘

## 背景

复盘只谈事实与改进项，不追责个人。这里围绕「单调栈求下一个更大元素」做一次整理，重点放在能直接落地的部分。

## 要点

- 栈内维护递减序列，弹出时即确定右侧第一个更大值
- 循环数组需要遍历两遍并取模
- 每个改进项都要有负责人与截止时间。

## 示例

```python
stack = []
res = [0] * n
for i, x in enumerate(a):
    while stack and a[stack[-1]] < x:
        res[stack.pop()] = x
    stack.append(i)
```

## 易错点

- 忘记把未弹出的下标置为 -1 会留下默认值

## 小结
