# Shell 脚本的健壮性

**日期**：2026-09-17　**领域**：Linux 与工程实践　**系列**：Linux 命令行与 Shell · 第 9 则

## 学习目标

让脚本在出错时尽早失败，方便定位。

## 核心要点

- set -e 遇错退出，-u 使用未定义变量报错，-o pipefail 让管道任一环失败即失败。
- trap 可以在退出或中断时执行清理逻辑。
- 关键步骤前后加日志，便于事后回溯。

## 示例

```bash
#!/usr/bin/env bash
set -euo pipefail
trap 'echo "cleanup"' EXIT
```

## 易错点

- set -e 在条件判断与命令替换中的行为有例外，需要理解其生效范围。

## 小结

三行头部约定能显著提升脚本可靠性。
