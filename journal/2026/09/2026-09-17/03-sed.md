# 流编辑：sed 的替换与行操作

**日期**：2026-09-17　**领域**：Linux 与工程实践　**系列**：Linux 命令行与 Shell · 第 3 则

## 学习目标

用 sed 完成批量文本替换与行级编辑。

## 核心要点

- s/old/new/g 是基础替换，g 表示一行内全部替换。
- -i 直接修改文件，macOS 需要写 -i '' 带一个空备份后缀。
- 用 -n 配合 p 可以只打印匹配行，地址范围如 10,20p 定位到具体行段。

## 示例

```bash
sed -i '' 's/localhost/127.0.0.1/g' config.ini
sed -n '/ERROR/p' app.log
```

## 易错点

- 直接 -i 修改生产配置前先备份，替换模式中的 / 需要转义或改用其他分隔符。

## 小结

sed 适合做精确、可复现的批量文本变更。
