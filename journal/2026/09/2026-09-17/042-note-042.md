## 背景

先把行为固定住再改结构，避免同时改两件事。这里围绕「前端渲染阻塞与关键路径」做一次整理，重点放在能直接落地的部分。

## 要点

- 同步脚本会阻塞解析，defer 与 module 在解析后按序执行
- 关键 CSS 内联可显著改善首屏
- 重构后接口不变，调用方无感。

## 示例

```js
<script src="app.js" defer></script>
```

## 易错点

- async 脚本执行顺序不可控，存在依赖时必须用 defer
