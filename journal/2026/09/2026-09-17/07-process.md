# 进程查看与管理

**日期**：2026-09-17　**领域**：Linux 与工程实践　**系列**：Linux 命令行与 Shell · 第 7 则

## 学习目标

快速定位占用资源的进程。

## 核心要点

- ps aux 看全量快照，top 或 htop 看动态排序。
- pgrep -fl 按名称定位进程，kill -15 是优雅退出信号。
- kill -9 不可捕获，会跳过清理逻辑，只能作为最后手段。

## 示例

```bash
pgrep -fl gunicorn
kill -15 $(pgrep -f 'gunicorn')
```

## 易错点

- 直接 -9 可能留下锁文件或半写状态，优先尝试 -15。

## 小结

先看再动，信号从温和开始。
