# 权限模型与 chmod / chown

**日期**：2026-09-17　**领域**：Linux 与工程实践　**系列**：Linux 命令行与 Shell

## 一句话说明

读懂 rwx 权限位并正确修改。

## 关键点

- 权限分属主、属组、其他三类，每类三位八进制数。
- 644 适合普通文件，755 适合可执行脚本与目录。
- chmod -R 递归修改要谨慎，误操作会破坏可执行位。

## 代码 / 命令

```bash
chmod 755 deploy.sh
chown -R app:app /srv/app
```

## 注意事项

- 对目录执行 777 会带来安全问题，优先用最小权限。

## 小结

权限问题优先查属主与八进制位，而不是直接 chmod 777。
