# 文本搜索：grep 的高频参数

**日期**：2026-09-17　**领域**：Linux 与工程实践　**系列**：Linux 命令行与 Shell

## 一句话说明

用最少的参数组合完成高效的文本检索。

## 关键点

- -r 递归、-n 显示行号、-i 忽略大小写是日常三件套。
- -E 启用扩展正则，-F 把模式当字面量可避免元字符误伤。
- -l 只列出文件名，-c 统计匹配行数，便于快速定位。

## 代码 / 命令

```bash
grep -rn --include='*.py' 'TODO' .
grep -c 'ERROR' app.log
```

## 注意事项

- 在二进制文件上递归搜索会输出乱码，加上 -I 可以跳过。

## 小结

掌握 -r -n -i -E 就能覆盖八成使用场景。
