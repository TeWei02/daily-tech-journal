# 磁盘与内存的查看方式

**日期**：2026-09-17　**领域**：Linux 与工程实践　**系列**：Linux 命令行与 Shell

## 一句话说明

判断是磁盘满还是内存压力。

## 关键点

- df -h 看挂载点使用率，du -sh * 定位目录占用。
- free -h 关注 available 而不是 free。
- 删除大文件后进程未释放句柄时，空间不会立刻回收。

## 代码 / 命令

```bash
df -h
du -sh /var/* | sort -h | tail -5
free -h
```

## 注意事项

- 看到 free 很小并不一定是问题，available 才代表可用量。

## 小结

先分清磁盘与内存两个维度再排查。
