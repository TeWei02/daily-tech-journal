# 单调栈求下一个更大元素：与相邻技术的配合

**日期**：2026-09-19　**领域**：算法　**编号**：34/115

## 背景

它很少单独出现，和上下游的约定决定了整体效果。这里围绕「单调栈求下一个更大元素」做一次整理，重点放在能直接落地的部分。

## 要点

- 栈内维护递减序列，弹出时即确定右侧第一个更大值
- 循环数组需要遍历两遍并取模
- 跨组件问题先在边界处抓包或打日志。

## 示例

```python
stack = []
res = [0] * n
for i, x in enumerate(a):
    while stack and a[stack[-1]] < x:
        res[stack.pop()] = x
    stack.append(i)
```

## 易错点

- 忘记把未弹出的下标置为 -1 会留下默认值

## 小结

单调栈求下一个更大元素 在与相邻技术的配合这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
