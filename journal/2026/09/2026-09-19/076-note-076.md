# CI 缓存与构建加速：与相邻技术的配合

**日期**：2026-09-19　**领域**：工程　**编号**：76/115

## 背景

它很少单独出现，和上下游的约定决定了整体效果。这里围绕「CI 缓存与构建加速」做一次整理，重点放在能直接落地的部分。

## 要点

- 缓存键要包含依赖清单哈希，否则会出现幽灵构建
- 缓存目录分层，把变动频繁的放上层
- 跨组件问题先在边界处抓包或打日志。

## 示例

```bash
- uses: actions/cache@v4
  with:
    key: deps-${{ hashFiles('**/requirements.txt') }}
```

## 易错点

- 缓存工具本身出错时会导致构建不稳定

## 小结

CI 缓存与构建加速 在与相邻技术的配合这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
