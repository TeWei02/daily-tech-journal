# 特征穿越与数据泄漏：与相邻技术的配合

**日期**：2026-09-19　**领域**：数据　**编号**：104/115

## 背景

它很少单独出现，和上下游的约定决定了整体效果。这里围绕「特征穿越与数据泄漏」做一次整理，重点放在能直接落地的部分。

## 要点

- 训练特征只能使用预测时刻之前可获得的信息
- 时间序列切分不要随机打乱
- 跨组件问题先在边界处抓包或打日志。

## 示例

```python
train = df[df.ts < cutoff]
valid = df[df.ts >= cutoff]
```

## 易错点

- 用全局统计量做标准化会造成泄漏

## 小结

特征穿越与数据泄漏 在与相邻技术的配合这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
