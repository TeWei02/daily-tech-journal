# 堆在 Top-K 场景的应用：实现原理与内部机制

**日期**：2026-09-14　**领域**：算法　**编号**：104/115

## 背景

知道底层怎么走，行为异常时才能判断卡在哪一层。这里围绕「堆在 Top-K 场景的应用」做一次整理，重点放在能直接落地的部分。

## 要点

- 求最大 K 个用最小堆，堆大小维持 K，复杂度 O(n log K)
- Python heapq 是最小堆，取相反数实现最大堆
- 原理清楚后，参数上限与限制条件基本能自己推导。

## 示例

```python
h = []
for x in nums:
    heappush(h, x)
    if len(h) > k:
        heappop(h)
```

## 易错点

- nlargest 在 K 很小时内部也会做优化，不必手写

## 小结

堆在 Top-K 场景的应用 在实现原理与内部机制这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
