## 要点

- 快慢指针原地覆盖，慢指针指向已确定的最后一个合法位置
- 返回长度而非新数组，调用方只读前 k 个
- 最小示例留着，回归时可直接复用。

## 示例

```python
k = 0
for x in a:
    if k == 0 or x != a[k - 1]:
        a[k] = x
        k += 1
```

## 易错点

- 比较对象是已写入的值而不是原数组前一位
