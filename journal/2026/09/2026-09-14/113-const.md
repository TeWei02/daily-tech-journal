# const 正确性与重载：实现原理与内部机制

**日期**：2026-09-14　**领域**：C/C++　**编号**：113/115

## 背景

知道底层怎么走，行为异常时才能判断卡在哪一层。这里围绕「const 正确性与重载」做一次整理，重点放在能直接落地的部分。

## 要点

- const 成员函数可被 const 对象调用，mutable 允许修改缓存字段
- 按值返回 const 会阻止移动语义
- 原理清楚后，参数上限与限制条件基本能自己推导。

## 示例

```cpp
int cached() const { return cache_; }
void update() { cache_ = compute(); }
```

## 易错点

- 为 const 与非 const 各写一份容易重复，用泛型辅助
