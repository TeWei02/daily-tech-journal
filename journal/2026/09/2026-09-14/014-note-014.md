## 要点

- 栈内维护递减序列，弹出时即确定右侧第一个更大值
- 循环数组需要遍历两遍并取模
- 最小示例留着，回归时可直接复用。

## 示例

```python
stack = []
res = [0] * n
for i, x in enumerate(a):
    while stack and a[stack[-1]] < x:
        res[stack.pop()] = x
    stack.append(i)
```
