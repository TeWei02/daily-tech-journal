# 分布式锁的续约与释放：代价与适用边界

**日期**：2026-09-22　**领域**：并发　**编号**：8/104

## 背景

任何方案都有不适用的时候，提前写清楚。这里围绕「分布式锁的续约与释放」做一次整理，重点放在能直接落地的部分。

## 要点

- 锁需带唯一值以便安全释放，避免删掉他人的锁
- 业务耗时长于租约要续约，续约失败应尽快中止
- 把不适用条件写进文档，避免误用。

## 示例

```cpp
SET lock:job 7f3a NX PX 30000
```

## 易错点

- 用固定值做锁会导致误删

## 小结

分布式锁的续约与释放 在代价与适用边界这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
