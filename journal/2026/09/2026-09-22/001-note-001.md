# 状态管理的单一数据源：代价与适用边界

**日期**：2026-09-22　**领域**：Web　**编号**：1/104

## 背景

任何方案都有不适用的时候，提前写清楚。这里围绕「状态管理的单一数据源」做一次整理，重点放在能直接落地的部分。

## 要点

- 派生状态不要重复存储，否则需要同步逻辑
- 异步状态用显式的加载与错误枚举表示
- 把不适用条件写进文档，避免误用。

## 示例

```js
const rows = computed(() => items.filter(i => i.ok))
```

## 易错点

- 把加载状态散落各处会导致界面闪烁

## 小结

状态管理的单一数据源 在代价与适用边界这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
