# 协程调度与阻塞调用：小规模验证方法

**日期**：2026-09-22　**领域**：并发　**编号**：95/104

## 背景

先用小样本验证假设，再决定是否推广。这里围绕「协程调度与阻塞调用」做一次整理，重点放在能直接落地的部分。

## 要点

- 在事件循环中做同步 IO 会阻塞所有协程，需放入线程池
- CPU 密集任务同样需要外移
- 试点结论要能复现。

## 示例

```cpp
await asyncio.to_thread(requests.get, url, timeout=3)
```

## 易错点

- sleep 必须用 asyncio.sleep，time.sleep 会卡住循环

## 小结

协程调度与阻塞调用 在小规模验证方法这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
