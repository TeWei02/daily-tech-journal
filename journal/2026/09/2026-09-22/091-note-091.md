# 表单校验的前后端分工：小规模验证方法

**日期**：2026-09-22　**领域**：Web　**编号**：91/104

## 背景

先用小样本验证假设，再决定是否推广。这里围绕「表单校验的前后端分工」做一次整理，重点放在能直接落地的部分。

## 要点

- 前端校验提升体验，后端校验保证正确性，二者都要有
- 统一错误码便于前端映射提示文案
- 试点结论要能复现。

## 示例

```js
{ "code": "INVALID_EMAIL", "field": "email" }
```

## 易错点

- 只在后端校验会导致用户反复提交

## 小结

表单校验的前后端分工 在小规模验证方法这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
