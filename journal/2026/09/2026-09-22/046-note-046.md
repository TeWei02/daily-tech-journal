## 要点

- Kahn 算法逐层剥入度为零的点，天然给出分层信息
- 若结果长度小于节点数说明有环
- 试点结论要能复现。

## 示例

```python
indeg = [0] * n
for u, v in edges:
    indeg[v] += 1
q = deque(i for i in range(n) if indeg[i] == 0)
```

## 易错点

- 有环时不要无限循环，需提前判断
