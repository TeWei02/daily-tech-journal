# 权限位与 ACL 的叠加：落到真实场景的改造

**日期**：2026-09-09　**领域**：Linux　**编号**：91/115

## 背景

把它放进真实流程，通常要补上配置、日志与失败分支。这里围绕「权限位与 ACL 的叠加」做一次整理，重点放在能直接落地的部分。

## 要点

- 目录的 x 位决定能否进入，读目录内容需要 r
- ACL 生效后 group 权限会显示为 mask
- 改造后别忘了补一次端到端验证。

## 示例

```bash
setfacl -m u:deploy:rx /srv/app
getfacl /srv/app
```

## 易错点

- umask 会影响新建文件，但不会回收已有权限
