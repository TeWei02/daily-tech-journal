# 协程调度与阻塞调用：实现原理与内部机制

**日期**：2026-09-09　**领域**：并发　**编号**：32/115

## 背景

知道底层怎么走，行为异常时才能判断卡在哪一层。这里围绕「协程调度与阻塞调用」做一次整理，重点放在能直接落地的部分。

## 要点

- 在事件循环中做同步 IO 会阻塞所有协程，需放入线程池
- CPU 密集任务同样需要外移
- 原理清楚后，参数上限与限制条件基本能自己推导。

## 示例

```cpp
await asyncio.to_thread(requests.get, url, timeout=3)
```

## 易错点

- sleep 必须用 asyncio.sleep，time.sleep 会卡住循环

## 小结

协程调度与阻塞调用 在实现原理与内部机制这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
