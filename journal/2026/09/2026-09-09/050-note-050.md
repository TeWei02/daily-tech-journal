# 特征穿越与数据泄漏：实现原理与内部机制

**日期**：2026-09-09　**领域**：数据　**编号**：50/115

## 背景

知道底层怎么走，行为异常时才能判断卡在哪一层。这里围绕「特征穿越与数据泄漏」做一次整理，重点放在能直接落地的部分。

## 要点

- 训练特征只能使用预测时刻之前可获得的信息
- 时间序列切分不要随机打乱
- 原理清楚后，参数上限与限制条件基本能自己推导。

## 示例

```python
train = df[df.ts < cutoff]
valid = df[df.ts >= cutoff]
```

## 易错点

- 用全局统计量做标准化会造成泄漏

## 小结

特征穿越与数据泄漏 在实现原理与内部机制这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
