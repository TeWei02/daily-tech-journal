# 权限位与 ACL 的叠加：实现原理与内部机制

**日期**：2026-09-09　**领域**：Linux　**编号**：2/115

## 背景

知道底层怎么走，行为异常时才能判断卡在哪一层。这里围绕「权限位与 ACL 的叠加」做一次整理，重点放在能直接落地的部分。

## 要点

- 目录的 x 位决定能否进入，读目录内容需要 r
- ACL 生效后 group 权限会显示为 mask
- 原理清楚后，参数上限与限制条件基本能自己推导。

## 示例

```bash
setfacl -m u:deploy:rx /srv/app
getfacl /srv/app
```

## 易错点

- umask 会影响新建文件，但不会回收已有权限

## 小结

权限位与 ACL 的叠加 在实现原理与内部机制这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
