# const 正确性与重载：落到真实场景的改造

**日期**：2026-09-09　**领域**：C/C++　**编号**：79/115

## 背景

把它放进真实流程，通常要补上配置、日志与失败分支。这里围绕「const 正确性与重载」做一次整理，重点放在能直接落地的部分。

## 要点

- const 成员函数可被 const 对象调用，mutable 允许修改缓存字段
- 按值返回 const 会阻止移动语义
- 改造后别忘了补一次端到端验证。

## 示例

```cpp
int cached() const { return cache_; }
void update() { cache_ = compute(); }
```

## 易错点

- 为 const 与非 const 各写一份容易重复，用泛型辅助
