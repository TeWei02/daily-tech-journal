# 内存对齐与 padding：落到真实场景的改造

**日期**：2026-09-09　**领域**：C/C++　**编号**：82/115

## 背景

把它放进真实流程，通常要补上配置、日志与失败分支。这里围绕「内存对齐与 padding」做一次整理，重点放在能直接落地的部分。

## 要点

- 结构体成员按对齐要求排布，调整顺序可减小体积
- alignas 指定对齐，reinterpret_cast 前要确认布局
- 改造后别忘了补一次端到端验证。

## 示例

```cpp
struct A { char c; int i; };   // 通常 8 字节
struct B { int i; char c; };   // 同样 8 字节但语义更紧凑
```

## 易错点

- 跨平台二进制协议不要直接 memcpy 结构体
