# TLS 握手耗时拆解：代价与适用边界

**日期**：2026-09-20　**领域**：网络　**编号**：35/54

## 背景

任何方案都有不适用的时候，提前写清楚。这里围绕「TLS 握手耗时拆解」做一次整理，重点放在能直接落地的部分。

## 要点

- 1-RTT 与 0-RTT 差异在会话复用，0-RTT 有重放风险
- 证书链不完整会导致部分客户端握手失败
- 把不适用条件写进文档，避免误用。

## 示例

```bash
openssl s_client -connect host:443 -servername host -tls1_3
```

## 易错点

- SNI 缺失会拿到默认站点证书

## 小结

TLS 握手耗时拆解 在代价与适用边界这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
