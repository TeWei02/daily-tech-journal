# 堆在 Top-K 场景的应用：代价与适用边界

**日期**：2026-09-20　**领域**：算法　**编号**：9/54

## 背景

任何方案都有不适用的时候，提前写清楚。这里围绕「堆在 Top-K 场景的应用」做一次整理，重点放在能直接落地的部分。

## 要点

- 求最大 K 个用最小堆，堆大小维持 K，复杂度 O(n log K)
- Python heapq 是最小堆，取相反数实现最大堆
- 把不适用条件写进文档，避免误用。

## 示例

```python
h = []
for x in nums:
    heappush(h, x)
    if len(h) > k:
        heappop(h)
```

## 易错点

- nlargest 在 K 很小时内部也会做优化，不必手写

堆在 Top-K 场景的应用 在代价与适用边界这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
