# 二分查找的三种边界写法：重构与可维护性

**日期**：2026-09-02　**领域**：算法　**编号**：70/115

## 背景

先把行为固定住再改结构，避免同时改两件事。这里围绕「二分查找的三种边界写法」做一次整理，重点放在能直接落地的部分。

## 要点

- 闭区间写法 lo<=hi，左闭右开写法 lo<hi，混用会导致死循环
- 求下界用 lower_bound，避免返回命中即返回
- 重构后接口不变，调用方无感。

## 示例

```python
lo, hi = 0, len(a)
while lo < hi:
    mid = (lo + hi) // 2
    if a[mid] < target:
        lo = mid + 1
    else:
        hi = mid
return lo
```

## 易错点

- mid 计算用 lo+(hi-lo)//2 可避免整型溢出

## 小结

二分查找的三种边界写法 在重构与可维护性这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
