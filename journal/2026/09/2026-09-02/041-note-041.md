# 熔断器状态机：测试与验证策略

**日期**：2026-09-02　**领域**：系统　**编号**：41/115

## 背景

测试要覆盖正常、边界与失败三类路径。这里围绕「熔断器状态机」做一次整理，重点放在能直接落地的部分。

## 要点

- 关闭、打开、半开三态，半开只放少量探测流量
- 基于滑动窗口的失败率比连续失败计数更稳
- 测试用例本身也要可维护。

## 示例

```python
if breaker.is_open():
    return fallback()
```

## 易错点

- 熔断恢复过快会导致反复抖动

## 小结

熔断器状态机 在测试与验证策略这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
