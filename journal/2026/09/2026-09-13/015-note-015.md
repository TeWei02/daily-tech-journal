# 分页查询的深翻页优化：方案对比与选型

**日期**：2026-09-13　**领域**：数据库　**编号**：15/115

## 背景

把候选方案的代价列清楚，选型就不再靠偏好。这里围绕「分页查询的深翻页优化」做一次整理，重点放在能直接落地的部分。

## 要点

- LIMIT 大偏移量会扫描并丢弃前 N 行
- 游标分页用上一页最后一条的键做条件
- 选型结论要写清前提，否则换个环境就不成立。

## 示例

```sql
SELECT * FROM t WHERE id > 100000 ORDER BY id LIMIT 20;
```

## 易错点

- 游标分页要求排序键唯一且稳定

## 小结

分页查询的深翻页优化 在方案对比与选型这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
