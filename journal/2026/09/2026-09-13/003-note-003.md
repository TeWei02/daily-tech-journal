# 权限位与 ACL 的叠加：方案对比与选型

**日期**：2026-09-13　**领域**：Linux　**编号**：3/115

## 背景

把候选方案的代价列清楚，选型就不再靠偏好。这里围绕「权限位与 ACL 的叠加」做一次整理，重点放在能直接落地的部分。

## 要点

- 目录的 x 位决定能否进入，读目录内容需要 r
- ACL 生效后 group 权限会显示为 mask
- 选型结论要写清前提，否则换个环境就不成立。

## 示例

```bash
setfacl -m u:deploy:rx /srv/app
getfacl /srv/app
```

## 易错点

- umask 会影响新建文件，但不会回收已有权限

## 小结

权限位与 ACL 的叠加 在方案对比与选型这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
