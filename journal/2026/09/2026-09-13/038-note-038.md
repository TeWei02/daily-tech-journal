# 熔断器状态机：方案对比与选型

**日期**：2026-09-13　**领域**：系统　**编号**：38/115

## 背景

把候选方案的代价列清楚，选型就不再靠偏好。这里围绕「熔断器状态机」做一次整理，重点放在能直接落地的部分。

## 要点

- 关闭、打开、半开三态，半开只放少量探测流量
- 基于滑动窗口的失败率比连续失败计数更稳
- 选型结论要写清前提，否则换个环境就不成立。

## 示例

```python
if breaker.is_open():
    return fallback()
```

## 易错点

- 熔断恢复过快会导致反复抖动

## 小结

熔断器状态机 在方案对比与选型这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
