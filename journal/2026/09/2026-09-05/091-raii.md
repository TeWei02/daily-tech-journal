## 背景

任何方案都有不适用的时候，提前写清楚。这里围绕「RAII 与资源释放顺序」做一次整理，重点放在能直接落地的部分。

## 要点

- 析构按构造逆序执行，成员按声明顺序构造、逆序析构
- 异常路径同样会析构，这正是 RAII 的价值
- 把不适用条件写进文档，避免误用。

## 示例

```cpp
struct File {
    FILE* f;
    File(const char* p) : f(fopen(p, "r")) {}
    ~File() { if (f) fclose(f); }
};
```
