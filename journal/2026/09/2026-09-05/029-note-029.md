# 分页查询的深翻页优化：与相邻技术的配合

**日期**：2026-09-05　**领域**：数据库　**编号**：29/115

## 背景

它很少单独出现，和上下游的约定决定了整体效果。这里围绕「分页查询的深翻页优化」做一次整理，重点放在能直接落地的部分。

## 要点

- LIMIT 大偏移量会扫描并丢弃前 N 行
- 游标分页用上一页最后一条的键做条件
- 跨组件问题先在边界处抓包或打日志。

## 示例

```sql
SELECT * FROM t WHERE id > 100000 ORDER BY id LIMIT 20;
```

## 易错点

- 游标分页要求排序键唯一且稳定

## 小结

分页查询的深翻页优化 在与相邻技术的配合这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
