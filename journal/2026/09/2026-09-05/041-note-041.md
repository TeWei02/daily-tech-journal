# 事件委托与动态节点：与相邻技术的配合

**日期**：2026-09-05　**领域**：Web　**编号**：41/115

## 背景

它很少单独出现，和上下游的约定决定了整体效果。这里围绕「事件委托与动态节点」做一次整理，重点放在能直接落地的部分。

## 要点

- 在容器上监听可覆盖后续新增节点，减少监听器数量
- 注意事件冒泡被 stopPropagation 截断的情况
- 跨组件问题先在边界处抓包或打日志。

## 示例

```js
list.addEventListener('click', e => {
  const row = e.target.closest('[data-id]')
  if (row) open(row.dataset.id)
})
```

## 易错点

- 过度委托到 document 会让排查变困难

## 小结

事件委托与动态节点 在与相邻技术的配合这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
