## 背景

它很少单独出现，和上下游的约定决定了整体效果。这里围绕「前端渲染阻塞与关键路径」做一次整理，重点放在能直接落地的部分。

## 要点

- 同步脚本会阻塞解析，defer 与 module 在解析后按序执行
- 关键 CSS 内联可显著改善首屏
- 跨组件问题先在边界处抓包或打日志。

## 示例

```js
<script src="app.js" defer></script>
```

## 易错点

- async 脚本执行顺序不可控，存在依赖时必须用 defer

## 小结

前端渲染阻塞与关键路径 在与相邻技术的配合这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
