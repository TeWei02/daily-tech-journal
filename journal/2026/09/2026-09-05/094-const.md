# const 正确性与重载：代价与适用边界

**日期**：2026-09-05　**领域**：C/C++　**编号**：94/115

## 背景

任何方案都有不适用的时候，提前写清楚。这里围绕「const 正确性与重载」做一次整理，重点放在能直接落地的部分。

## 要点

- const 成员函数可被 const 对象调用，mutable 允许修改缓存字段
- 按值返回 const 会阻止移动语义
- 把不适用条件写进文档，避免误用。

## 示例

```cpp
int cached() const { return cache_; }
void update() { cache_ = compute(); }
```

## 易错点

- 为 const 与非 const 各写一份容易重复，用泛型辅助
