# 单调栈求下一个更大元素：代价与适用边界

**日期**：2026-09-05　**领域**：算法　**编号**：84/115

## 背景

任何方案都有不适用的时候，提前写清楚。这里围绕「单调栈求下一个更大元素」做一次整理，重点放在能直接落地的部分。

## 要点

- 栈内维护递减序列，弹出时即确定右侧第一个更大值
- 循环数组需要遍历两遍并取模
- 把不适用条件写进文档，避免误用。

## 示例

```python
stack = []
res = [0] * n
for i, x in enumerate(a):
    while stack and a[stack[-1]] < x:
        res[stack.pop()] = x
    stack.append(i)
```

## 易错点

- 忘记把未弹出的下标置为 -1 会留下默认值
