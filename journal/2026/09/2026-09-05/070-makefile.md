# Makefile 与任务编排：与相邻技术的配合

**日期**：2026-09-05　**领域**：工具　**编号**：70/115

## 背景

它很少单独出现，和上下游的约定决定了整体效果。这里围绕「Makefile 与任务编排」做一次整理，重点放在能直接落地的部分。

## 要点

- 把幂等操作做成任务，配合 .PHONY 避免同名文件干扰
- 并行目标要考虑依赖关系
- 跨组件问题先在边界处抓包或打日志。

## 示例

```yaml
.PHONY: test lint
test:
	pytest -q
lint:
	ruff check .
```

## 易错点

- 隐式规则可能带来意外行为，可显式声明

## 小结

Makefile 与任务编排 在与相邻技术的配合这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
