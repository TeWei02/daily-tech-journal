## 背景

它很少单独出现，和上下游的约定决定了整体效果。这里围绕「去重与近似的取舍」做一次整理，重点放在能直接落地的部分。

## 要点

- 精确去重占内存，HyperLogLog 误差可控但不可枚举
- 集合交并场景要注意误差叠加
- 跨组件问题先在边界处抓包或打日志。

## 示例

```python
from datasketch import HyperLogLog
hll = HyperLogLog(p=14)
```

## 易错点

- 对账场景不能使用近似算法

## 小结

去重与近似的取舍 在与相邻技术的配合这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
