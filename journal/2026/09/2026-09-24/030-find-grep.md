# find 与 grep 的组合排查：基础用法与最小示例

**日期**：2026-09-24　**领域**：Linux　**编号**：30/104

## 背景

先写出能跑通的最小示例，把输入输出钉死，再谈扩展。这里围绕「find 与 grep 的组合排查」做一次整理，重点放在能直接落地的部分。

## 要点

- find 用 -print0 配合 xargs -0 处理含空格文件名
- grep -r 前先用 find 缩小范围能省大量 IO
- 最小示例留着，回归时可直接复用。

## 示例

```bash
find . -name '*.log' -mtime -1 -print0 | xargs -0 grep -l ERROR
```

## 易错点

- xargs 默认按空白分割，遇到空格文件会断
