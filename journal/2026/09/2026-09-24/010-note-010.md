# 二分查找的三种边界写法：基础用法与最小示例

**日期**：2026-09-24　**领域**：算法　**编号**：10/104

## 背景

先写出能跑通的最小示例，把输入输出钉死，再谈扩展。这里围绕「二分查找的三种边界写法」做一次整理，重点放在能直接落地的部分。

## 要点

- 闭区间写法 lo<=hi，左闭右开写法 lo<hi，混用会导致死循环
- 求下界用 lower_bound，避免返回命中即返回
- 最小示例留着，回归时可直接复用。

## 示例

```python
lo, hi = 0, len(a)
while lo < hi:
    mid = (lo + hi) // 2
    if a[mid] < target:
        lo = mid + 1
    else:
        hi = mid
return lo
```

## 易错点

- mid 计算用 lo+(hi-lo)//2 可避免整型溢出

## 小结

二分查找的三种边界写法 在基础用法与最小示例这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
