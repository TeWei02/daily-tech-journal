# 堆在 Top-K 场景的应用：代码评审关注点

**日期**：2026-09-07　**领域**：算法　**编号**：33/115

## 背景

评审优先看契约与失败路径，其次才是实现技巧。这里围绕「堆在 Top-K 场景的应用」做一次整理，重点放在能直接落地的部分。

## 要点

- 求最大 K 个用最小堆，堆大小维持 K，复杂度 O(n log K)
- Python heapq 是最小堆，取相反数实现最大堆
- 把重复出现的意见沉淀成团队约定。

## 示例

```python
h = []
for x in nums:
    heappush(h, x)
    if len(h) > k:
        heappop(h)
```

## 易错点

- nlargest 在 K 很小时内部也会做优化，不必手写
