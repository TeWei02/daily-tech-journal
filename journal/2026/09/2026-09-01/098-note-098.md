# 并查集路径压缩与按秩合并：测试与验证策略

**日期**：2026-09-01　**领域**：算法　**编号**：98/115

## 背景

测试要覆盖正常、边界与失败三类路径。这里围绕「并查集路径压缩与按秩合并」做一次整理，重点放在能直接落地的部分。

## 要点

- find 递归写路径压缩，union 按秩合并保证树高近似对数
- 带权并查集需要在 find 中同步更新权值
- 测试用例本身也要可维护。

## 示例

```python
def find(x):
    while x != p[x]:
        p[x] = p[p[x]]
        x = p[x]
    return x
```

## 易错点

- 只压缩不按秩合并也能均摊很优，但最坏情况退化

## 小结

并查集路径压缩与按秩合并 在测试与验证策略这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
