# 无锁队列的 ABA 问题：并发与线程安全

**日期**：2026-09-01　**领域**：并发　**编号**：60/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「无锁队列的 ABA 问题」做一次整理，重点放在能直接落地的部分。

## 要点

- 比较并交换需要版本号或标签位才能识别 ABA
- 内存回收（如 RCU、引用计数）与无锁结构必须一起设计
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```cpp
bool push(Node* n) {
  Node* head = head_.load();
  n->next = head;
  return head_.compare_exchange_weak(head, n);
}
```

## 易错点

- 在 C++ 中用 std::atomic<Node*> 直接 CAS 存在内存回收风险

## 小结

无锁队列的 ABA 问题 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
