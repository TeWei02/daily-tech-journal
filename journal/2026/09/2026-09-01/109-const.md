# const 正确性与重载：测试与验证策略

**日期**：2026-09-01　**领域**：C/C++　**编号**：109/115

## 背景

测试要覆盖正常、边界与失败三类路径。这里围绕「const 正确性与重载」做一次整理，重点放在能直接落地的部分。

## 要点

- const 成员函数可被 const 对象调用，mutable 允许修改缓存字段
- 按值返回 const 会阻止移动语义
- 测试用例本身也要可维护。

## 示例

```cpp
int cached() const { return cache_; }
void update() { cache_ = compute(); }
```

## 易错点

- 为 const 与非 const 各写一份容易重复，用泛型辅助

## 小结

const 正确性与重载 在测试与验证策略这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
