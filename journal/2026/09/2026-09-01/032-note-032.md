# 权限位与 ACL 的叠加：并发与线程安全

**日期**：2026-09-01　**领域**：Linux　**编号**：32/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「权限位与 ACL 的叠加」做一次整理，重点放在能直接落地的部分。

## 要点

- 目录的 x 位决定能否进入，读目录内容需要 r
- ACL 生效后 group 权限会显示为 mask
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```bash
setfacl -m u:deploy:rx /srv/app
getfacl /srv/app
```

## 易错点

- umask 会影响新建文件，但不会回收已有权限

## 小结

权限位与 ACL 的叠加 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
