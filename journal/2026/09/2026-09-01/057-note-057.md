# 状态管理的单一数据源：并发与线程安全

**日期**：2026-09-01　**领域**：Web　**编号**：57/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「状态管理的单一数据源」做一次整理，重点放在能直接落地的部分。

## 要点

- 派生状态不要重复存储，否则需要同步逻辑
- 异步状态用显式的加载与错误枚举表示
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```js
const rows = computed(() => items.filter(i => i.ok))
```

## 易错点

- 把加载状态散落各处会导致界面闪烁

## 小结

状态管理的单一数据源 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
