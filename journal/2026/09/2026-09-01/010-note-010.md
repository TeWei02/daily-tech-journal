# 单调栈求下一个更大元素：并发与线程安全

**日期**：2026-09-01　**领域**：算法　**编号**：10/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「单调栈求下一个更大元素」做一次整理，重点放在能直接落地的部分。

## 要点

- 栈内维护递减序列，弹出时即确定右侧第一个更大值
- 循环数组需要遍历两遍并取模
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```python
stack = []
res = [0] * n
for i, x in enumerate(a):
    while stack and a[stack[-1]] < x:
        res[stack.pop()] = x
    stack.append(i)
```

## 易错点

- 忘记把未弹出的下标置为 -1 会留下默认值

## 小结

单调栈求下一个更大元素 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
