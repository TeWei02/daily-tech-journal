# ss 与 lsof 定位端口占用：并发与线程安全

**日期**：2026-09-01　**领域**：Linux　**编号**：28/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「ss 与 lsof 定位端口占用」做一次整理，重点放在能直接落地的部分。

## 要点

- ss -ltnp 比 netstat 更快且信息完整
- lsof -p 看到进程持有的全部 fd 与文件
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```bash
ss -ltnp 'sport = :8080'
lsof -i :8080 -sTCP:LISTEN
```

## 易错点

- 容器内 ss 可能看不到宿主机命名空间的连接

## 小结

ss 与 lsof 定位端口占用 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
