# 序列化性能与安全性：并发与线程安全

**日期**：2026-09-01　**领域**：Python　**编号**：6/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「序列化性能与安全性」做一次整理，重点放在能直接落地的部分。

## 要点

- pickle 反序列化不可信数据等于执行任意代码
- 跨语言场景用 JSON 或 msgpack，注意浮点与时间精度
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```python
import json
payload = json.dumps(rec, ensure_ascii=False, separators=(',', ':'))
```

## 易错点

- 默认 ensure_ascii=True 会让中文体积翻三倍

## 小结

序列化性能与安全性 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
