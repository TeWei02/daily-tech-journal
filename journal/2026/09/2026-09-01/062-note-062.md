# 协程调度与阻塞调用：并发与线程安全

**日期**：2026-09-01　**领域**：并发　**编号**：62/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「协程调度与阻塞调用」做一次整理，重点放在能直接落地的部分。

## 要点

- 在事件循环中做同步 IO 会阻塞所有协程，需放入线程池
- CPU 密集任务同样需要外移
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```cpp
await asyncio.to_thread(requests.get, url, timeout=3)
```

## 易错点

- sleep 必须用 asyncio.sleep，time.sleep 会卡住循环

## 小结

协程调度与阻塞调用 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
