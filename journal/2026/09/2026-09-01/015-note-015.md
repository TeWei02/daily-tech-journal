# 双指针处理有序数组去重：并发与线程安全

**日期**：2026-09-01　**领域**：算法　**编号**：15/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「双指针处理有序数组去重」做一次整理，重点放在能直接落地的部分。

## 要点

- 快慢指针原地覆盖，慢指针指向已确定的最后一个合法位置
- 返回长度而非新数组，调用方只读前 k 个
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```python
k = 0
for x in a:
    if k == 0 or x != a[k - 1]:
        a[k] = x
        k += 1
```

## 易错点

- 比较对象是已写入的值而不是原数组前一位

## 小结

双指针处理有序数组去重 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
