# 分页查询的深翻页优化：并发与线程安全

**日期**：2026-09-01　**领域**：数据库　**编号**：44/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「分页查询的深翻页优化」做一次整理，重点放在能直接落地的部分。

## 要点

- LIMIT 大偏移量会扫描并丢弃前 N 行
- 游标分页用上一页最后一条的键做条件
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```sql
SELECT * FROM t WHERE id > 100000 ORDER BY id LIMIT 20;
```

## 易错点

- 游标分页要求排序键唯一且稳定

## 小结

分页查询的深翻页优化 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
