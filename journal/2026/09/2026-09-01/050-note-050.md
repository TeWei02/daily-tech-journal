# 分支策略与长期分支风险：并发与线程安全

**日期**：2026-09-01　**领域**：工程　**编号**：50/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「分支策略与长期分支风险」做一次整理，重点放在能直接落地的部分。

## 要点

- 长期分支合并回主干的冲突成本随时间线性增长
- 短分支 + 频繁集成能显著降低合并风险
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```bash
git fetch origin
git rebase origin/main
```

## 易错点

- 对已推送的公共分支 rebase 会改写他人历史

## 小结

分支策略与长期分支风险 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
