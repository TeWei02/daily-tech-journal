# 事务隔离级别与幻读：并发与线程安全

**日期**：2026-09-01　**领域**：数据库　**编号**：42/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「事务隔离级别与幻读」做一次整理，重点放在能直接落地的部分。

## 要点

- RR 下间隙锁可避免幻读，但会带来更多锁等待
- RC 下同一事务内两次读可能不一致
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```sql
SET SESSION TRANSACTION ISOLATION LEVEL READ COMMITTED;
START TRANSACTION;
```

## 易错点

- 长事务会拖住 undo 清理，务必控制时长

## 小结

事务隔离级别与幻读 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
