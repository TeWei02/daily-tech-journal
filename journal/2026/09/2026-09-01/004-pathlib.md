# pathlib 路径操作：并发与线程安全

**日期**：2026-09-01　**领域**：Python　**编号**：4/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「pathlib 路径操作」做一次整理，重点放在能直接落地的部分。

## 要点

- Path 是不可变对象，所有操作返回新对象
- resolve() 会展开符号链接并规范化大小写
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```python
root = Path('data').resolve()
for p in root.rglob('*.csv'):
    handle(p.with_suffix('.parquet'))
```

## 易错点

- 不要用字符串拼接路径，跨平台会出错

## 小结

pathlib 路径操作 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
