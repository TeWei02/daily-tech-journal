# 密码存储与哈希选择：并发与线程安全

**日期**：2026-09-01　**领域**：安全　**编号**：73/115

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「密码存储与哈希选择」做一次整理，重点放在能直接落地的部分。

## 要点

- 使用专门的口令哈希，如 bcrypt 或 argon2，务必加盐
- 迭代成本要可调，以便随硬件升级提高
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```python
from argon2 import PasswordHasher
ph = PasswordHasher()
ph.hash(pw)
```

## 易错点

- SHA-256 加盐仍可被 GPU 高速爆破

## 小结

密码存储与哈希选择 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
